# 二叉树

遍历方式

- 深度优先遍历

  - 前序遍历（递归法，迭代法）

    ```java
    List<Integer> list = new ArrayList<>();
    
    // 递归法
    public void traversal(TreeNode root) {
    	if (root != null) {
            list.add(root.val);
            traversal(root.left);
            traversal(root.right);
        }
    }
    
    // 迭代法
    public void traversal(TreeNode root) {
        if (root == null) {
            return;
        }
        Deque<TreeNode> stack = new LinkedList<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            list.add(node.val);
            // 先加右孩子节点
            if (node.right != null) {
                stack.push(node.right);
            }
            // 再加左孩子节点
            if (node.right != null) {
                stack.push(node.right);
            }
        }
    }
    ```

  - 中序遍历（递归法，迭代法）

    ```java
    List<Integer> list = new ArrayList<>();
    
    // 递归法
    public void traversal(TreeNode root) {
    	if (root != null) {
            traversal(root.left);
            list.add(root.val);
            traversal(root.right);
        }
    }
    
    // 迭代法
    public void traversal(TreeNode root) {
        Stack<TreeNode> que = new LinkedList<>();
        TreeNode cur = root;
        while (cur != null || !que.isEmpty()) {
            if (cur != null) {
                que.push(cur);
                cur = cur.left;
            } else {
    			cur = que.pop();
                list.add(cur.val);
                cur = cur.right;
            }
        }
    }
    ```

  - 后序遍历（递归法，迭代法）

    ```java
    List<Integer> list = new ArrayList<>();
    
    // 递归法
    public void traversal(TreeNode root) {
    	if (root != null) {
            traversal(root.left);
            traversal(root.right);
            list.add(root.val);
        }
    }
    
    // 迭代法
    public void traversal(TreeNode root) {
        if (root == null) {
            return;
        }
        Deque<TreeNode> stack = new LinkedList<>();
        stack.push(root);
        // 经过这个while循环，stack中节点的顺序： 中右左
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            list.add(node.val);
    		if (node.left != null) {
                stack.push(node.left);
            }
            if (node.right != null) {
                stack.push(node.right);
            }
        }
        // 经过翻转后，stack中节点的顺序为： 左右中
        Collections.reverse(list);
    }
    ```
