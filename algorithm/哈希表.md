#### 1.1 [字母异位词分组](https://leetcode.cn/problems/group-anagrams/)

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

**示例 1:**

- 输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
- 输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

---

这里设置了一个Map集合，**Map<字符串，该字符串的字母异位词>**

```java
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] sorted = s.toCharArray();
        Arrays.sort(sorted);
        List<String> list = map.getOrDefault(new String(sorted), new ArrayList<>());
        list.add(s);
        map.put(new String(sorted), list);
    }
    return new ArrayList<>(map.values());
}
```



#### 1.2 [找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 

**异位词**

 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1:**

- 输入: s = "cbaebabacd", p = "abc"
- 输出: [0,6]

解释:

- 起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
- 起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

---



```java
public List<Integer> findAnagrams(String s, String t) {
    List<Integer> res = new ArrayList<>();
    if (s.length() < t.length()) {
        return res;
    }
    char[] need = t.toCharArray();
    Arrays.sort(need);

    int len = t.length();
    for (int i = 0; i + len <= s.length(); i++) {
        char[] temp = s.substring(i, i + len).toCharArray();
        Arrays.sort(temp);
        if (Arrays.equals(need, temp)) {
            res.add(i);
        }
    }
    return res;
}
```

```java
public int[] intersection(int[] nums1, int[] nums2) {
    Set<Integer> reSet = new HashSet<>();
    Set<Integer> set = new HashSet<>();
    for (int num : nums1) {
        set.add(num);
    }
    for (int num : nums2) {
        if (set.contains(num)) {
            reSet.add(num);
        }
    }
    int[] res = new int[reSet.size()];
    int pos = 0;
    for (int num : reSet) {
        res[pos++] = num;
    }
    return res;
}
```





### 3. [快乐数](https://leetcode.cn/problems/happy-number/)

![image-20250213024051814](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250213024051814.png)

---

关键就是如何判定快乐数

由题目可知，在循环过程中，要么会变成1，要么就无限循环

那么用一个set集合存储过程中出现的所有数字，如果出现重复，那么就返回false

```java
public boolean isHappy(int n) {
    Set<Integer> set = new HashSet<>();
    while (n != 1) {
        if (set.contains(n)) {
            return false;
        }
        set.add(n);
        n = cal(n);
    }
    return true;
}
// 计算快乐数
private int cal(int n) {
    int res = 0;
    while (n != 0) {
        int i = n % 10;
        res += i * i;
        n /= 10;
    }
    return res;
}
```

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    int[] res = new int[2];
    for (int i = 0; i < nums.length; i++) {
        if (map.containsKey(target - nums[i])) {
            res[0] = i;
            res[1] = map.get(target - nums[i]);
            break;
        }
        map.put(nums[i], i);
    }
    return res;
}
```

### 5. [四数相加 II](https://leetcode.cn/problems/4sum-ii/)

![image-20250213031619896](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250213031619896.png)

---

1. 首先定义 一个map，key放a和b两数之和，value 放a和b两数之和出现的次数。
2. 遍历大A和大B数组，统计两个数组元素之和，和出现的次数，放到map中。
3. 定义int变量count，用来统计 a+b+c+d = 0 出现的次数。
4. 再遍历大C和大D数组，找到如果 0-(c+d) 在map中出现过的话，就用count把map中key对应的value也就是出现次数统计出来。
5. 最后返回统计值 count 就可以了

```java
public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums1.length; i++) {
        for (int j = 0; j < nums2.length; j++) {
            int sum = nums1[i] + nums2[j];
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }
    }
    int res = 0;
    for (int i = 0; i < nums3.length; i++) {
        for (int j = 0; j < nums4.length; j++) {
            int sum = nums3[i] + nums4[j];
            res += map.getOrDefault(0 - sum, 0);
        }
    }
    return res;
}
```



### 6. [三数之和](https://leetcode.cn/problems/3sum/)

![image-20250213031741217](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250213031741217.png)

---

使用双指针

![15.三数之和](https://code-thinking.cdn.bcebos.com/gifs/15.%E4%B8%89%E6%95%B0%E4%B9%8B%E5%92%8C.gif)

首先将数组**排序**，然后有一层for循环，i从下标0的地方开始，同时定一个下标left 定义在 i+1 的位置上，定义下标right 在数组结尾的位置上。

接下来如何移动left 和right呢， 如果nums[i] + nums[left] + nums[right] > 0 就说明 此时三数之和大了，因为数组是排序后了，所以right下标就应该向左移动，这样才能让三数之和小一些。

如果 nums[i] + nums[left] + nums[right] < 0 说明 此时 三数之和小了，left 就向右移动，才能让三数之和大一些，直到left与right相遇为止。

##### 去重逻辑

1. nums[i]

这是第一个元素，在一次成功的遍历之后，应将 nums[i] 与前面的 nums[i - 1]进行比对，若有重复则跳过

特别的对于 i = 0来说，不存在去重，所以

```java
if (i != 0 && nums[i - 1] == nums[i]) {
    continue;
}
```

2. nums[left]和nums[right]

```java
while (right > left) {
    if (nums[i] + nums[left] + nums[right] > 0) {
        right--;
        // 去重 right
        while (left < right && nums[right] == nums[right + 1]) right--;
    } else if (nums[i] + nums[left] + nums[right] < 0) {
        left++;
        // 去重 left
        while (left < right && nums[left] == nums[left - 1]) left++;
    } else {
    }
}
```

实际上这个去重对运行效率的提升没有帮助，因为它只是把需要执行的逻辑提前执行了，但并没有减少 判断的逻辑

所以这种去重 是可以不加的。 仅仅是 把去重的逻辑提前了而已

##### 最终实现

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) {
            break;
        }
        if (i != 0 && nums[i - 1] == nums[i]) {
            continue;
        }
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum < 0) {
                left++;
            } else if (sum > 0) {
                right--;
            } else {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                left++;
                while(left < right && nums[right - 1] == nums[right]) {
                    right--;
                }
                right--;
            }
        }
    }
    return res;
}
```



### 7. 四数之和

四数之和，和三数之和是一个思路，都是使用双指针法, 基本解法就是在三数之和的基础上再套一层for循环。

```java
public List<List<Integer>> fourSum(int[] nums, int target) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 3; i++) {
        if (nums[i] >= 0 && nums[i] > target) {
            break;
        }
        if (i != 0 && nums[i - 1] == nums[i]) {
            continue;
        }
        for (int j = i + 1; j < nums.length - 2; j++) {
            if (nums[i] + nums[j] > target && nums[j] >= 0) {
                break;
            }
            if (j != i + 1 && nums[j - 1] == nums[j]) {
                continue;
            }
            int left = j + 1, right = nums.length - 1;
            while (left < right) {
                int sum = nums[i] + nums[j] + nums[left] + nums[right];
                if (sum < target) {
                    left++;
                } else if (sum > target) {
                    right--;
                } else {
                    res.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    left++;
                    while (left < right && nums[right - 1] == nums[right]) {
                        right--;
                    }
                    right--;
                }
            }
        }
    }
    return res;
}
```
