### 2. [设计链表](https://leetcode.cn/problems/design-linked-list/)

先确定链表节点Node类，使用内部类

```java
class Node {
    int val;
    Node next;

    Node(int val, Node next) {
        this.val = val;
        this.next = next;
    }
}
```

单链表

有头节点 + 无尾节点

```java
class MyLinkedList {
    private int length;
    private Node head;

    public MyLinkedList() {
        length = 0;
        head = new Node(0, null);
    }

    public int get(int index) {
        Node node = getNode(index);
        return node == null ? -1 : node.val;
    }

    public void addAtHead(int val) {
        addAtIndex(0, val);
    }

    public void addAtTail(int val) {
        addAtIndex(length, val);

    }

    private Node getNode(int index) {
        if (index < 0 || index > length) {
            return null;
        }
        Node node = head.next;
        while (index != 0) {
            node = node.next;
            index--;
        }
        return node;
    }

    public void addAtIndex(int index, int val) {
        if (index < 0 || index > length) {
            return;
        }
        Node newNode = new Node(val, null);
        Node pre = head;
        for (int i = 0; i < index; i++) {
            pre = pre.next;
        }
        newNode.next = pre.next;
        pre.next = newNode;
        length++;
    }

    public void deleteAtIndex(int index) {
        if (index < 0 || index >= length || length == 0) {
            return;
        }
        Node pre = head;
        for (int i = 0; i < index; i++) {
            pre = pre.next;
        }
        Node nodeDelete = pre.next;
        pre.next = nodeDelete.next;
        length--;
    }
}
```

### 4. [两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)

- 链表操作题，可以搞一个头节点，`ListNode h = new ListNode(-1, head);`
- 实际操作

```java
public ListNode swapPairs(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode h = new ListNode();
    h.next = head;
    ListNode pre = h, p = head;
    while (p != null && p.next != null) {
        ListNode q = p.next;
        ListNode nextTun = q.next;
        // 核心操作
        pre.next = q;
        q.next = p;
        p.next = nextTun;
        pre = p;
        p = p.next;
    }
    return h.next;
}
```

### 5. [删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

双指针

**加个头节点**

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode h = new ListNode(-1, head);
    ListNode slow = h, fast = h;
    for (int i = 1; i <= n; i++) {
        fast = fast.next;
    }
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }
    slow.next = slow.next.next;
    return h.next;
}
```

### 7. [环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)

1. 判断是否有环

可以使用快慢指针法，分别定义 fast 和 slow 指针，从头结点出发，fast指针每次移动两个节点，slow指针每次移动一个节点，如果 fast 和 slow指针在途中相遇 ，说明这个链表有环。

fast指针一定先进入环中，如果fast指针和slow指针相遇的话，一定是**在环中相遇**，这是毋庸置疑的。

因为fast是走两步，slow是走一步，**其实相对于slow来说，fast是一个节点一个节点的靠近slow的**，所以fast一定可以和slow重合。



![](https://code-thinking.cdn.bcebos.com/gifs/141.%E7%8E%AF%E5%BD%A2%E9%93%BE%E8%A1%A8.gif)

2. 如何确定环的入口

假设从头结点到环形入口节点 的节点数为x。 环形入口节点到 fast指针与slow指针相遇节点 节点数为y。 从相遇节点 再到环形入口节点节点数为 z。

![image-20250212153319244](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250212153319244.png)

- 在相遇时：slow指针走过的节点数为: `x + y`， fast指针走过的节点数：`x + y + n*(y + z)`

  n为fast指针在环内走了n圈才遇到slow指针， （y+z）为 一圈内节点的个数A

- 因为fast指针是一步走两个节点，slow指针一步走一个节点

   所以 fast指针走过的节点数 = slow指针走过的节点数 * 2： `x + y + n (y + z) = (x + y) * 2`

- 两边同时消除掉一个 `x + y`，得：`x + y = n (y + z)`

- 因为要求得是环的入口处，求得是 x ，所以将上式转换为：`x = n (y + z) - y` 

- 再从n(y+z)中提出一个 （y+z）来，整理公式之后为如下公式：`x = (n - 1) (y + z) + z` 

  注意这里**n一定是大于等于1**的，因为 fast指针至少要多走一圈才能相遇slow指针

  - 当 n = 1 的时候，公式被化简为 `x = z`

    这就意味着，**从头结点出发一个指针，从相遇节点 也出发一个指针，这两个指针每次只走一个节点， 那么当这两个指针相遇的时候就是 环形入口的节点**。

  - 当 n > 1的时候，也就是在相遇节点出发的指针在环里多走了 `(n - 1)`圈
