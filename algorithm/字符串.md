## 1. [反转字符串](https://leetcode.cn/problems/reverse-string/)

```java
public void reverseString(char[] s) {
    int start = 0, end = s.length - 1;
    while (start <end) {
        char t = s[start];
        s[start++] = s[end];
        s[end--] = t;
    }
}
```



## 2. [反转字符串 II](https://leetcode.cn/problems/reverse-string-ii/)

核心就是这个`reverseString(chars, i, Math.min(s.length(), i + k) - 1);`

```java
public String reverseStr(String s, int k) {
    if (s == null || s.length() == 1) {
        return s;
    }
    char[] chars = s.toCharArray();
    for (int i = 0; i < s.length(); i += k * 2) {
        reverseString(chars, i, Math.min(s.length(), i + k) - 1);
    }
    return new String(chars);
}
```



## 3. [反转字符串中的单词](https://leetcode.cn/problems/reverse-words-in-a-string/)

1. 先去除字符串中多余的空格：左右两边以及单词之间多余的空格
2. 翻转字符串
3. 翻转单个单词

```java
public String reverseWords(String s) {
    if (s == null) {
        return s;
    }
    // 去重多余的空格
    char[] chars = removeSpace(s);
    // 翻转字符串
    reverseString(chars, 0, chars.length - 1);
    // 翻转单个单词
    int start = 0;
    while (start < chars.length) {
        int end = start;
        while (end < chars.length && chars[end] != ' ') {
            end++;
        }
        reverseString(chars, start, end - 1);
        start = end + 1;
    }
    return new String(chars);
}

public void reverseString(char[] chars, int start, int end) {
    while (start < end) {
        char ch = chars[start];
        chars[start++] = chars[end];
        chars[end--] = ch;
    }
}

public char[] removeSpace(String s) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++) {
        // 删去头部空格
        if (sb.length() == 0 && s.charAt(i) == ' ') {
            continue;
        }
        // 删除单词之间多余空格 和 字符串最后的空格
        if (s.charAt(i) == ' ') {
            sb.append(" ");
            while (i + 1 < s.length() && s.charAt(i + 1) == ' ') {
                i++;
            }
        } else {
            sb.append(s.charAt(i));
        }
    }
    // 如果最后一个字符是空格的话，删掉
    if (sb.charAt(sb.length() - 1) == ' ') {
        sb.deleteCharAt(sb.length() - 1);
    }
    return sb.toString().toCharArray();
}
```
