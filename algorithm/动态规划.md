#### 6. [整数拆分](https://leetcode.cn/problems/integer-break/)

（1）确定dp数组及其定义

dp[i] : 分拆数字i，可以得到的最大乘积dp[i]

（2）确定递推公式

关于dp[i]怎么得到

- 一个是j * (i - j) 直接相乘。

- 一个是j * dp[i - j]，相当于是拆分(i - j)

举个例子：i = 5时

```java
dp[5] :
	1 + 4  =>  	max(1 * 4, 1 * dp[4])  
    2 + 3  =>	max(2 * 3, 2 * dp[3])
    3 + 2  =>  	max(3 * 2, 3 * dp[2])
    4 + 1  =>   max(4 * 1, 4 * dp[1])
dp[5] = max(dp[5], max(j * (i - j), j * dp[i - i]));
其中最后一种情况可以忽略，因为第一种情况就包括了第四种情况
```

至于j是不拆分的，拆分j的情况都在遍历过程中计算过了。

或者这样说，关于 j * (i - j)，两个都在变化，那么就固定一个，拆分另一个，动中求静

（4）遍历顺序

dp[i]依赖的是dp[i - j]的状态，所以一定是从前往后遍历

#### **滚动数组版本**

实质就是**压缩状态**

使用二维数组的时候，`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);`

如果把`dp[i - 1]`这层的拷贝到`dp[i]`这层上，那么表达式完全可以是：

`dp[i][j] = max(dp[i][j], d[i][j - weight[i]] + value[i])`

那么这样，与其把上一层的拷贝到这层来，那不如直接用一个一维数组，我们就可以压缩每层的状态，只用一个一维数组储存每次迭代的状态，这就是滚动数组的由来，条件就是上一层可以重复利用。

（1）dp数组的定义

`dp[j]`: 表示容量为 j 的背包，所装物品的最大的价值为`dp[j]`

（2）递推公式

由上可知：`dp[j] = max(dp[j], dp[j - weight[i]] + value[i])`

（3）初始化

紧扣定义，dp[j]表示：容量为j的背包，所背的物品价值可以最大为dp[j]，那么dp[0] = 0，毋庸置疑

对于其他下标，dp数组在推到的时候，一定取得是最大值，如果题目给的价值都是正整数，那么非0下标都初始化为0就可以了。

（4）遍历顺序

```java
for(int i = 0; i < weight.size(); i++) { // 遍历物品
    for(int j = bagWeight; j >= weight[i]; j--) { // 遍历背包容量
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);

    }
} 
```

背包容量倒序遍历是为了保证物品只被放入一次

比如：物品0的重量weight[0] = 1，价值value[0] = 15

如果正序遍历

dp[1] = max(dp[1],  dp[1 - weight[0]] + value[0]) = 15

dp[2] = max(dp[2],  dp[2 - weight[0]] + value[0]) = 30

此时dp[2]就是30了，它是由加入了两个物品0得来的，因为dp[2] 来源于 dp[1]，dp[1]中已经放过了，所以不行



- 为什么倒序遍历就行呢

dp[2] = max(dp[2],  dp[2 - weight[0]] + value[0]) = 15

dp[1] = max(dp[1],  dp[1 - weight[0]] + value[0]) = 15

从后往前循环，每次得到的状态都不会与之前的状态重合，保证了每个物品只取一次

- 那么为什么二维数组它就不用倒序呢？

因为对于二维dp，`dp[i][j]`都是通过上一层即`dp[i - 1][j]`计算而来，**本层的`dp[i][j]`并不会被覆盖！**

- 再看遍历顺序，两个for循环可不可以调换呢

  **不可以**

​	因为一维的写法，背包容量是一定要倒序遍历的，如果先遍历背包，那么每个`dp[j]`就只会放入一个物品

1. 定义dp数组

`dp[i][j]`：最多有 i 个 0 和 j 个 1 的最大子集的**大小**为`dp[i][j]`

这不是一个狭义上的二维dp数组，而是两个一维的dp数组复合起来了。或者说这是一个三维的dp降维到二维的

2. 递推关系

```java
for (String str : strs) {
	int one = 0, zero = 0;
    // 相当于物品 外层循环
	for (char ch : str.toCharArray()) {
		if (ch == '0') {
   	 		zero++;
		} 
		if (ch == '1') {
    		one++;
		}
        // 两各维度的背包容量 逆序
        // zero 和 one 的前后无所谓
        for (int i = m; i >= zero; i--) {
            for (int j = n; j >= one; j--) {
                dp[i][j] = Math.max(dp[i][j], dp[i - zero][j - one] + 1);
            }
        }
    }
}
```





## 三 完全背包

#### 二维数组版本

有N件物品和一个最多能背重量为W的背包。第i件物品的重量是weight[i]，得到的价值是value[i] 。每件物品都有无限个（也就是可以放入背包多次），求解将哪些物品装入背包里物品价值总和最大。

完全背包和01背包问题唯一不同的地方就是，每种物品有无限件。

1. **确定dp数组以及下标含义**

`dp[i][j]`：从下标为[0, i]的商品中选，每个物品可以被取无限次，放入容量为 j 的背包中，价值总和最大为多少

2. **递推公式**

关于`dp[i][j]`

- 不放物品 i

  那么只能从[i, i - 1]中的商品选，来装入容量为 j 的背包

  `dp[i][j] = dp[i - 1][j]`

- 放物品 i

  背包先空出 物品 i 的空间，所以容量为 j - weight[ i ]

  由于完全背包中，物品可以放无限个，因此即使此次不放物品 i ， 但是背包中仍可能含有物品 i ，这也是完全背包和01背包的根本区别之处

  `dp[i][j] = dp[i][j - weight[i]] + value[i]`

所以由此得出递推公式：

`dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]), j >= weight[i]`

3. **初始化**

- 第一列，背包容量为0，那么 `dp[i][0] = 0`

- 第一行，物品0的存取情况，当 `j >= weight[0]`时，`dp[0][j]`能装下几个物品0就装几个物品0

4. **递推顺序**

二维数组，外层内层顺序无所谓，正序遍历



#### 滚动数组版本

1. dp数组定义 以及 下标含义

dp[j] ：容量 为 j 的背包最多能装入的最大价值

2. 递归公式

将二维数组压缩成一维数组，也就是将上一层的拷贝下来，将`dp[i - 1][j]`拷贝到`dp[i][j]`

那么递推公式就由

`dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]), j >= weight[i]`

变成：

`dp[i][j] = Math.max(dp[i][j], dp[i][j - weight[i]] + value[i]), j >= weight[i]`

不用担心`dp[i - 1][j]`会覆盖`dp[i][j]`，因为在计算当前`dp[i][j]`的时候，它还是空的





那么将改造过的二维数组压缩成一维数组

`dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i])；`

这个一维数组和01背包的一维数组是一样的，但是重点就是遍历顺序不一样了



3. 遍历顺序

在01背包中，一维数组的for循环遍历是固定的，必须外循环物品，内循环背包，内循环还得是倒置遍历

对于完全背包而言，一维数组的两个for循环嵌套顺序是无所谓的，并且都是正序遍历。

因为`dp[j]`是根据下标 j 之前所对应的`dp[j]`计算出来的，只要保证下标 j 之前的`dp[j]`都是经过计算的就行了

正常



##### 滚动数组

`dp[i][j] = dp[i - 1][j] + dp[i][j - coins[i]], j >= coins[i]`

状态压缩

`dp[i][j] = dp[i][j] + dp[i][j - coins[i]], j >= coins[i]`

转为一维形式

`dp[j] += dp[j - coins[i]], j >= coins[i]`

它的初始化只要初始化`dp[0] = 1`，因为它不依赖于上方数组，相当于只要初始化第一列，而不用初始化第一行

**遍历顺序**

如果是求完全背包能装入的**最大价值**，那么两个for循环先后无所谓，因为对于求和来说，元素的顺序不影响

本题要求的是**方法个数**，且每个方法个数都是**组合数**，那这对for循环的先后顺序就有要求了

- 外层物品，内层背包

  ```java
  for (int i = 0; i < coins.size(); i++) { // 遍历物品
      for (int j = coins[i]; j <= amount; j++) { // 遍历背包容量
          dp[j] += dp[j - coins[i]];
      }
  }
  ```

  假设：coins[0] = 1，coins[1] = 5。

  那么就是先把1加入计算，然后再把5加入计算，得到的方法数量只有{1, 5}这种情况。而不会出现{5, 1}的情况。这算出来的就是**组合数**

- 外层背包，内层物品

  ```java
  for (int j = 0; j <= amount; j++) { // 遍历背包容量
      for (int i = 0; i < coins.size(); i++) { // 遍历物品
          if (j - coins[i] >= 0) 
              dp[j] += dp[j - coins[i]];
      }
  }
  ```

  背包的每一个容量都经过了1和5的计算，包含了{1，5}和{5，1}两种情况，这算出来的就是**排列数**

这次换成了树状结构

这道题是**树形dp**的入门，因为是在树上进行状态转移的，那么就要确定遍历方式和递归函数

遍历方式采用**后序遍历**，因为要通过左右孩子的递归函数返回值来做下一步计算。

如果抢了当前结点，那么就不能抢两个孩子；如果没抢当前结点，那么就可以考虑抢两个孩子



由于是二叉树和dp的结合，那么下面以递归三步（递归函数的参数和返回值、终止条件、单层遍历逻辑）和dp五步进行结合

1. **递归函数的参数和返回值**

要求一个节点 偷与不偷 的两个状态所得到的金钱，那么返回值就是一个长度为2的数组。

```java
public int[] robTree(TreeNode tree);
```

这里的返回数组就是dp数组

**dp数组以及下标含义**

- 下标为0记录不偷该节点所得到的最大金额
- 下标为1记录偷该节点所得到的最大金额

所以本题的dp数组只用一个长度为2的数组即可，它记录的就是当前结点的状态。

**在父节点的逻辑中调用递归，获得两个孩子的状态**



2. **终止条件**

在遍历过程中，遇到空结点，无论偷不偷都是0，所以直接返回

```java
if (tree == null) {
    return new int[]{0, 0};
}
```

这也相当于dp数组的初始化了



3. **递归顺序**

明确是后序遍历，通过递归左右结点，获取左右结点 偷与不偷的金额

```java
int[] leftRob = robTree(tree.left);
int[] rightRob = robTree(tree.right);
```



4. **确定单层递归的逻辑**

- 如果偷当前节点，那么左右节点都不能偷

  `dp[1] = leftRob[0] + rightRob[0] + tree.val;`

- 如果不偷当前节点，那么可以**考虑**偷左右节点

​	`dp[0] = Math.max(leftRob[0], leftRob[1]) + Math.max(rightRob[0], rightRob[1])`

最后返回dp数组给上一级节点

1. dp数组以及下标含义

这题实际上是第一题的扩展，第一次只可以买卖一次，所以一天只可能是两个状态：

- `dp[i][0]`在这天持有
- `dp[i][1]`在这天不持有

这题由于可以买卖两次，所以一天就可以存在**四个状态**：

- `dp[i][0]`在这天第一次持有
- `dp[i][1]`在这天第一次不持有
- `dp[i][2]`在这天第二次持有
- `dp[i][3]`在这天第二次不持有



2. 递推公式

`dp[i][0]`在这天第一次持有，可以由两个状态推出

- 第 i 天买入	`-price[i]`
- 在 i - 1天及之前就持有了，`dp[i - 1][0]`

- 在 i - 1天及之前就不持有了，`dp[i - 1][1]`

- 第 i 天第二次买入，那就是 **第 i - 1 天第一次不持有的钱** 减去 **今日买入的钱**`dp[i - 1][1] - price[i]`
- 在 i - 1天及之前就第二次持有了，`dp[i - 1][2]`

`dp[i][3]`在这天第二次不持有，可以由两个状态推出

- 第 i 天第二次卖出，那么金额就是 第 i - 1 天第二次持有的钱 加上 今天卖出的钱	`dp[i - 1][2] + price[i]`

`dp[0][0] = dp[0][2] = 0`

public int maxProfit(int[] prices) {
    int[][] dp = new int[prices.length][4];

    dp[0][1] = dp[0][3] = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        dp[i][0] = Math.max(-prices[i], dp[i - 1][0]);
        dp[i][1] = Math.max(dp[i - 1][0] + prices[i], dp[i - 1][1]);
        dp[i][2] = Math.max(dp[i - 1][1] - prices[i], dp[i - 1][2]);
        dp[i][3] = Math.max(dp[i - 1][2] + prices[i], dp[i - 1][3]);
    }
    return dp[prices.length - 1][3];
}
```

public int maxProfit(int[] prices) {
    int n = 2 * 2 + 1;
    int[][] dp = new int[prices.length][n];

    dp[0][1] = dp[0][3] = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        for (int j = 1; j <= 2 * 2; j += 2) {
            dp[i][j] = Math.max(dp[i - 1][j - 1] - prices[i], dp[i - 1][j]);
            dp[i][j + 1] = Math.max(dp[i - 1][j] + prices[i], dp[i - 1][j + 1]);
        }
    }
    return dp[prices.length - 1][n - 1];
}
```

连续递增的子序列 可以由两个下标 l 和 r（l < r）确定，如果对于每个 l <= i < r，都有 nums[i] < nums[i + 1] ，那么子序列 [nums[l], nums[l + 1], ..., nums[r - 1], nums[r]] 就是连续递增子序列。

示例 1：

- 输入：nums = [1,3,5,4,7]
- 输出：3
- 解释：最长连续递增序列是 [1,3,5], 长度为3。尽管 [1,3,5,7] 也是升序的子序列, 但它不是连续的，因为 5 和 7 在原数组里被 4 隔开。

因为本题要求连续递增子序列，所以就只要比较nums[i]与nums[i - 1]，而不用去比较nums[j]与nums[i] （j是在0到i之间遍历）

3. 初始化

每一个 i 对应的 dp[i] 至少是1，即该连续递增子序列就是他自己

4. 递推顺序

#### 1. [回文子串](https://leetcode.cn/problems/palindromic-substrings/)

给定一个字符串，你的任务是计算这个字符串中有多少个回文**子串**。

具有不同开始位置或结束位置的子串，即使是由相同的字符组成，也会被视作不同的子串。

示例 1：

- 输入："abc"
- 输出：3
- 解释：三个回文子串: "a", "b", "c"

---

本题的重点是如何用动态规划处理回文串判断

统计数量只要在判断为true的分支里进行计数就行了

1. **dp数组及其下标的含义**

布尔类型的`dp[i][j]`：表示区间范围 [i, j] 的子串是否是回文子串，如果是为true，否则为false。

2. **递推公式**

总体上为两种情况，即s[i] 和 s[j] 是否相等

- s[i] != s[j]

  那么 `dp[i][j]`直接为false

- s[i] == s[j]

  这又要分为三种情况了

  - **i == j**

    s[i] 和 s[j] 是同一个字符串，那么肯定是true了

  - **i + 1 == j**

    比如字符串"aa"

  - **i 和 j 相差大于 1**

    比如"abccba"，此时 s[i] == s[j]，那么我们就要看[i + 1, j - 1]之间的字符串是否是回文串，如果是则为true，否则为false

由此得出递推公式

```java
if (s[i] == s[j]) {
    // 情况 一和二
    if (j - i <= 1) {
        dp[i][j] = true;
    // 情况 三
    } else if (dp[i + 1][j - 1]) {
        dp[i][j] = true;
    }
}
```

3. **初始化**

所有的`dp[i][j]`都应初始化为false

4. **递推顺序**

从递推公式可以看出`dp[i][j]`依赖于`dp[i + 1][j - 1]`

#### 2. [两个字符串的删除操作](https://leetcode.cn/problems/delete-operation-for-two-strings/)

给定两个单词 word1 和 word2，找到使得 word1 和 word2 相同所需的最小步数，每步可以删除任意一个字符串中的一个字符。

示例：

- 输入: "sea", "eat"
- 输出: 2
- 解释: 第一步将"sea"变为"ea"，第二步将"eat"变为"ea"

---

1. 确定dp数组及下标含义

`dp[i][j]`：以i-1为结尾的字符串word1，和以j-1位结尾的字符串word2，想要达到相等，所需要删除元素的最少次数。

2. 递推公式

对于`dp[i][j]`来说，最重要的就是比较s[i - 1] 和 t[j - 1]是否相等

- s[i - 1] == t[j - 1]

  不用执行删除操作，所以操作次数为`dp[i - 1][j - 1]`

- s[i - 1] != t[j - 1]

  - 删s[i - 1]，最少的操作次数为`dp[i - 1][j] + 1`
  - 删t[j - 1]，最少的操作次数为`dp[i][j - 1] + 1`
  - 同时删s[i - 1]和 t[j - 1]，最少的操作次数为`dp[i - 1][j - 1] + 2`

  取**三者最小值**

3. 初始化

从递推公式看出，依赖于左方、左上方、上方。所以`dp[i][0]`和`dp[0][j]`都要初始化

根据定义，`dp[i][0]`表示当word2为空字符串时，以 i - 1 为结尾的字符串 word1要删除多少个元素才能和word2相同，明显 `dp[i][0] = i`

`dp[0][j]`同理

```java
for (int i = 0; i <= word1.size(); i++) dp[i][0] = i;
for (int j = 0; j <= word2.size(); j++) dp[0][j] = j;
```

4. 遍历顺序

从上到下，从左到右

#### 3. [不同的子序列](https://leetcode.cn/problems/distinct-subsequences/)

还是看两种情况，s[i - 1] 和 t[j - 1]是否相等

- s[i - 1] == t[j - 1]

  - 考虑用 s[i - 1]来匹配，个数为 `dp[i - 1][j - 1]`，即不考虑当前s子串和t子串的最后一位字母

#### 4. [编辑距离](https://leetcode.cn/problems/edit-distance/)

给你两个单词 word1 和 word2，请你计算出将 word1 转换成 word2 所使用的最少操作数 。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

示例 1：

- 输入：word1 = "horse", word2 = "ros"
- 输出：3
- 解释： horse -> rorse (将 'h' 替换为 'r') rorse -> rose (删除 'r') rose -> ros (删除 'e')

---

1. dp数组及下标定义

`dp[i][j]` 表示以**下标i-1为结尾的字符串word1**，和以**下标j-1为结尾的字符串word2**的最近编辑距离

2. 递推公式

`dp[i][j]` 还是由两个状态决定

- s[i - 1] == t[j - 1]

  由于最后两个字符相等，所以不用进行任何操作，那么`dp[i][j] = dp[i-1][j-1]` 

- s[i - 1] != t[j - 1]

  由于最后两个字符不了，那么就要进行编辑操作了

  - word1删除一个元素（添加操作）

    word1删除一个元素，那就是以 下标 i - 2为结尾的word1和 与 j - 1为结尾的word2的最近编辑距离再加上一个操作

    `dp[i][j] = dp[i - 1][j] + 1` 

    这个实际上就等价于添加操作，因为word2添加一个元素 等价于 word1删除一个元素

  - word2删除一个元素

    word2删除一个元素，那就是以 下标 i - 1为结尾的word1和 与 j - 2为结尾的word2的最近编辑距离再加上一个操作

    `dp[i][j] = dp[i][j - 1] + 1` 

  - 替换操作

    替换word1[i - 1]，使其与word2[j - 1]相同，此时不用增删元素，所以

    `dp[i][j] = dp[i - 1][j - 1] + 1`

  取三者最小

3. 初始化

依赖于左边、左上方以及正上方，所以要初始化`dp[i][0]`和`dp[0][j]`

- `dp[i][0]`：以下标i-1为结尾的字符串word1，和空字符串word2的最近编辑距离

​	显然要执行 i 次删除操作，即`dp[i][0] = i`

- `dp[i][0]`：空字符串word1，和下标j-1为结尾的字符串word2的最近编辑距离

​	显然要执行 j 次删除操作，即`dp[0][j] = j`

4. 遍历顺序

正常
