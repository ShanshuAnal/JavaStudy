# 单调栈

通常是**一维数组**，要寻找**任一个元素的右边**或者**左边第一个比自己大或者小的元素**的位置，此时我们就要想到可以用单调栈了。

时间复杂度为O(n)。



#### 1. [每日温度](https://leetcode.cn/problems/daily-temperatures/)

请根据每日 气温 列表，重新生成一个列表。对应位置的输出为：要想观测到更高的气温，至少需要等待的天数。如果气温在这之后都不会升高，请在该位置用 0 来代替。

例如，给定一个列表 temperatures = [73, 74, 75, 71, 69, 72, 76, 73]，你的输出应该是 [1, 1, 4, 2, 1, 1, 0, 0]。

提示：气温 列表长度的范围是 [1, 30000]。每个气温的值的均为华氏度，都是在 [30, 100] 范围内的整数。

1. 单调栈里存放的元素是什么？

单调栈里只需要存放**元素的下标 i **就可以了，如果需要使用对应的元素，直接T[i]就可以获取。

2. 单调栈里元素是递增还是递减呢？

**顺序的描述为 从栈顶到栈底 的顺序**

这里使用**递增循序**，因为只有递增的时候，栈里要加入一个元素 i 的时候，才知道栈顶元素在数组中右面第一个比栈顶元素大的元素是 i 。



使用单调栈的规则

- 当前遍历的元素T[i]小于栈顶元素T[st.top()]的情况
- 当前遍历的元素T[i]等于栈顶元素T[st.top()]的情况
- 当前遍历的元素T[i]大于栈顶元素T[st.top()]的情况

#### 4. [接雨水](https://leetcode.cn/problems/trapping-rain-water/)

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

示例 1：

- 输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
- 输出：6
- 解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水

##### 暴力解法

首先明确**按列计算**

![image-20250116145708416](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250116145708416.png)

只要吧每一列雨水的高度求出来就好了

每列雨水的高度取决于，该列 **左侧最高的柱子** 和 **右侧最高的柱子** 中 **最矮的那个柱子**的高度

![image-20250116145831404](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250116145831404.png)

比如求列4的雨水高度

其左侧最高时列3，高度为2；右侧最高是列7，高度为3；列4自身高度为1

所以雨水量 = min(2，3) - 1

一样的方法，只要从头遍历一遍新的列，累加每列雨水的体积，就得出总雨水的体积了

注意，第一个柱子和最后一个柱子不接水

```java
int res = 0;
int n = height.length;
for (int i = 0; i < n; i++) {
    // 第一个柱子和最后一个柱子不接雨水
    if (i == 0 || i == n - 1) {
        continue;
    }
    
    // 左边柱子最高的高度
    int leftH = height[i];
    for (int j = i - 1; j >= 0; j--) {
        leftH = Math.max(leftH, height[j]);
    }
    
    // 右边柱子最高的高度
    int rightH = height[i];
    for (int j = i + 1; j < n; j++) {
        rightH = Math.max(rightH, height[j]);
    }
    
    res += Math.min(leftH, rightH) - height[i];
}
return res;
```

##### 双指针法

在暴力解法中，为了得到两边的最高高度，使用了双指针来遍历，每个柱子都向左右遍历了一次，这里包含了大量的重复计算。

可以**事先计算每列左右两侧最矮列的高度**，记录在一个数组里

```java
public int trap(int[] height) {
    int[] maxLeft = new int[height.length];
    int[] maxRight = new int[height.length];

    // 1. 预先求得每个柱子左边最高高度
    maxLeft[0] = height[0];
    for (int i = 1; i < height.length; i++) {
        maxLeft[i] = Math.max(maxLeft[i - 1], height[i]);
    }
    // 2. 预先求得每个柱子右边最高高度
    maxRight[height.length - 1] = height[height.length - 1];
    for (int i = height.length - 2; i >= 0; i--) {
        maxRight[i] = Math.max(maxRight[i + 1], height[i]);
    }
    // 3. 开始计算面积
    int res = 0;
    for (int i = 0; i < height.length; i++) {
        res += Math.min(maxLeft[i], maxRight[i]) - height[i];
    }
    return res;
}
```

##### 单调栈解法

单调栈就是保持栈内的元素有序

通常是一维数组，要寻找任一个元素的右边或者左边第一个比自己大或者比自己小的元素的位置

接雨水这道题，就是寻找**最右边最大元素**和**最左边最大元素**

单调栈解法是按照**行方向**来计算雨水的

![image-20250116151119619](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250116151119619.png)

单调栈内的顺序：从**栈顶都栈底**是从**小到大**的顺序

因为一旦发现添加的柱子高度 大于 栈顶元素了，那么此时就出现了凹槽

栈顶元素就是凹槽底部的柱子，栈顶的第二个元素就是凹槽左边的柱子，添加的元素就是凹槽右边的柱子

![image-20250116152007675](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250116152007675.png)

遇到相同高度的柱子时，将栈里的旧元素下标弹出，加入新元素的下标



**处理逻辑**

先将下标0的柱子加入到栈中，然后从下标为1开始遍历所有主子

- 如果当前柱子的高度 小于 栈顶柱子的高度

  那么直接加入到栈中

- 如果当前柱子的高度 等于 栈顶柱子的高度

  更新栈顶元素，因为遇到相同高度的柱子，要用最右边的柱子来计算宽度

- 如果当前柱子的高度 大于 栈顶柱子的高度

  将**栈顶元素弹出，这就是凹槽的底部**，下标记为 mid，对应的高度是height[mid]（上图中 1）

  此时**栈顶元素就是凹槽左边的位置**，下标为stack.peek()，对应高度是height[stack.peek()] （上图 2）

  **当前遍历元素就是凹槽右边的位置**，下标为 i ，对应高度为 height[i] （上图3）

  那么雨水的高度 h = min(height[stack.peek()], height[i]) - height[mid]

  ​	  雨水的宽度 w = i - stack.peek() - 1

  sum += h * w

  ```java
  public int trap(int[] height) {
      Deque<Integer> stack = new LinkedList<>();
      int res = 0;
      for (int i = 0; i < height.length; i++) {
          while (!stack.isEmpty() && height[stack.peek()] < height[i]) {
              int mid = height[stack.pop()];
              if (!stack.isEmpty()) {
                  int h = Math.min(height[stack.peek()], height[i]) - mid;
                  int w = i - stack.peek() - 1;
                  res += h * w;
              }
          }
          stack.push(i);
      }
      return res;
  }
  ```

##### **暴力解法**

本题是要找每个柱子**左右两边第一个小于该柱子的柱子**

```java
public int largestRectangleArea(int[] heights) {
    int res = 0;
    for (int i = 0; i < heights.length; i++) {
        int left = i, right = i;
        for (; left >= 0; left--) {
            if (heights[left] < heights[i]) {
                break;
            }
        }
        for (; right < heights.length; right++) {
            if (heights[right] < heights[i]) {
                break;
            }
        }
        int w = right - left - 1;
        int h = heights[i];
        res = Math.max(res, w * h);
    }
    return res;
}
```

##### **双指针**

暴力解法计算每个柱子的左右两边第一个小于该柱子的柱子有重复。像接雨水一样，可以首先计算好。

```java
public int largestRectangleArea(int[] heights) {
    // 1. 计算每个柱子左边第一个小于该柱子的柱子
    int[] minLeftIndex = new int[heights.length];
    minLeftIndex[0] = -1;
    for (int i = 1; i < heights.length; i++) {
        int t = i - 1;
        while (t >= 0 && heights[t] >= heights[i]) {
            // 既然heights[t]大于heights[i]
            // 那么肯定要找比heights[t]小的
            // 与其t--，不如直接 t = minLeftIndex[t]
            // 因为minLeftIndex[t]存储就是heights[t]左边第一个比它小的柱子
            t = minLeftIndex[t];
        }
        minLeftIndex[i] = t;
    }

    // 2. 计算每个柱子右边第一个小于该柱子的柱子
    int[] minRightIndex = new int[heights.length];
    minRightIndex[heights.length - 1] = heights.length;
    for (int i = heights.length - 2; i >= 0; i--) {
        int t = i + 1;
        while (t < heights.length && heights[t] >= heights[i]) {
            t = minRightIndex[t];
        }
        minRightIndex[i] = t;
    }
    
    // 3. 开始计算面积
    int res = 0;
    for (int i = 0; i < heights.length; i++) {
        int sum = heights[i] * (minRightIndex[i] - minLeftIndex[i] - 1);
        res = Math.max(res, sum);
    }
    return res;
}
```



##### 单调栈

接雨水 是找每个柱子左右两边第一个大于该柱子高度的柱子，而本题是找**每个柱子左右两边第一个小于该柱子的柱子。**

这就要求单调栈里的顺序是：从栈顶到栈底，从大到小

栈顶和栈顶的下一个元素以及要入栈的三个元素组成了我们要求最大面积的高度和宽度

- 情况一：当前遍历的元素heights[i]大于栈顶元素heights[st.top()]的情况

  直接 stack.push(i)

- 情况二：当前遍历的元素heights[i]等于栈顶元素heights[st.top()]的情况

  弹出并压入 i

- 情况三：当前遍历的元素heights[i]小于栈顶元素heights[st.top()]的情况

  ```java
  while (!st.empty() && heights[i] < heights[st.top()]) { // 注意是while
      int mid = st.top();
      st.pop();
      if (!st.empty()) {
          int left = st.top();
          int right = i;
          int w = right - left - 1;
          int h = heights[mid];
          result = max(result, w * h);
      }
  }
  ```


**注意：**在构造单调栈的时候要进特别处理。

- 如果数组本身就是升序的，比如[2, 3, 4, 5]，那么算法只会执行情况一，一直都没有走 情况三 计算结果的哪一步，所以最后输出的就是0了。

  所以要在结尾加一个0，这样就会让栈中的所有元素走到情况三的逻辑

- 如果数组本身就是升序的，比如 [8,6,4,2]，在 8 入栈后，6 开始与8 进行比较，此时我们得到 mid（8），right（6），但是得不到 left。因为 将 8 弹出之后，栈里没有元素了，那么为了避免空栈取值，直接跳过了计算结果的逻辑。

  之后又将6 加入栈（此时8已经弹出了），然后 就是 4 与 栈口元素 6 进行比较，周而复始，那么计算的最后结果result就是0。
