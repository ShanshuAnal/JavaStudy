## 一 DFS 和 BFS

#### 1. DFS代码框架

因为 dfs 需要搜索一个方向 并且 需要不断地回溯，所以用递归来实现

```java
void dfs(参数) {
    if (终止条件) {
        存放结果;
        return;
    }

    for (选择：本节点所连接的其他节点) {
        处理节点;
        dfs(图，选择的节点); // 递归
        回溯，撤销处理结果
    }
}
```

- 确定递归参数

  DFS 需要集合结构来保存所有路径，需要以为数组保存单一路径，这种保存结果的数据，可以定义一个成员变量，避免传递参数过多

  ```java
  List<int[]> res; 	// 保存所有符合条件的所有路径
  int[] path;			// 起点到终点的路径
  void dfs(图， 目前所有的节点)
  ```

- 终止条件

  终止条件不只是结束本层递归，也是添加路径的时候。

- 处理目前搜索节点出发的路径

  一个for循环来处理

图的存储两种方式：邻接表和邻接矩阵

- **邻接矩阵**

```java
import java.util.*;
 
public class Main {
    // 存储单条路径
    private static List<Integer> path = new LinkedList<>();
    // 存储所有路径集合
    private static List<List<Integer>> res = new ArrayList<>();
     
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
         
        // 邻接矩阵写法
        int[][] graph = new int[n + 1][n + 1];
         
        // 存储边的信息
        for (int i = 0; i < m; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            graph[s][e] = 1;
        }
        
        // 不管怎么回溯递归，起始节点一定是 1
        path.add(1);
        // 开始深度遍历
        dfs(graph, 1, n);
         
        // ACM模式的打印有讲究
        if (res.isEmpty()) {
            System.out.println(-1);
        }
        for (List<Integer> list : res) {
            for (int i = 0; i < list.size() - 1; i++) {
                System.out.print(list.get(i) + " ");
            }
            // 这题要求最后一个元素后面不能有空格，所以最后单独打印
            System.out.println(list.get(list.size() - 1));
        }
    }
     
    // 深度遍历
    public static void dfs(int[][] graph, int x, int n) {
        // 当遍历到 n 节点的时候，终止
        if (x == n) {
            res.add(new ArrayList<>(path));
            return;
        }
         
        // 遍历临界矩阵第 x 行的边
        for (int i = 1; i <= n; i++) {
            // 若与遍历节点有边，则进行回溯
            if (graph[x][i] == 1) {
                path.add(i);
                dfs(graph, i, n);
                path.remove(path.size() - 1);
            }
        }
    }
}
```

- 邻接表

```java
import java.util.*;
 
public class Main {
    private static List<Integer> path = new LinkedList<>();
    private static List<List<Integer>> res = new ArrayList<>();
     
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
         
        // 邻接表
        List<LinkedList<Integer>> graph = new ArrayList<>(n + 1);
        // 初始化邻接表
        for (int i = 0; i <= n; i++) {
            graph.add(new LinkedList<>());
        }
         
        for (int i = 0; i < m; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            // 使用邻接表表示 s -> e 是相连的
            graph.get(s).add(e);
        }
         
        path.add(1);
        dfs(graph, 1, n);
         
        if (res.isEmpty()) {
            System.out.println(-1);
        }
        for (List<Integer> list : res) {
            for (int i = 0; i < list.size() - 1; i++) {
                System.out.print(list.get(i) + " ");
            }
            System.out.println(list.get(list.size() - 1));
        }  
    }
     
    public static void dfs(List<LinkedList<Integer>> graph, int x, int n) {
        if (x == n) {
            res.add(new ArrayList<>(path));
            return;
        }
        // 找到x指向的节点
        for (int i : graph.get(x)) {
            path.add(i);
            dfs(graph, i, n);
            path.remove(path.size() - 1);
        }
    }
}
```



#### 3. BFS代码框架

广搜的搜索方式就适合于解决两个点之间的最短路径问题，只要BFS只要搜到终点一定是一条最短路径

![图二](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/20220825102653.png)

```java
// 表示四个方向
int[][] dir = {
    {0, 1}, // 上
    {1, 0}, // 右 
    {-1, 0}, // 左
    {0, -1}; // 下
}

// grid是一个地图，visited是一个标记数组，x y是搜索节点的下标
public void bfs(int[][] grid, boolean[][] visited, int x, int y) {
    Deque<int[]> que = new LinkedList<>();
    que.offer(new int[]{x, y});
    visited[x][y] = true;
    
    // 遍历队列中的元素
    while (!que.isEmpty()) {
        int[] cur = que.poll();
        // 获取当前节点坐标
        int curx = cur[0];
        int cury = cur[1];
        // 向当前节点的四个方向 左右上下去遍历
        for (int i = 0; i < 4; i++) {
            int newx = curx + dir[i][0];
            int newy = cury + dir[i][1];
            
            if (newx < 0 || newx >= grid.length ||
                 newy < 0 || newy >= grid[0].length){
                continue;
            }
            if (!visited[newx][newy]) {
                que.offer(new int[]{newx, newy});
                visited[newx][newy] = true;
            }
        }
    }
}
```

每个岛屿只能由 水平方向和竖直方向上相邻的陆地连接形成

说白了就是找连通分量的个数

搜寻过程中，将一个连通分量中的节点全部标记成已访问，每遍历一个连通分量，记录加一

所以本题的搜索过程用DFS还是BFS无所谓

##### DFS

```java
public class Main {
    private static int[][] dir = {
        {0, 1},
        {0, -1},
        {1, 0},
        {-1, 0}
    };
    
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        
        int[][] grid = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        
        boolean[][] visited = new boolean[m][n];
        
        int res = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 一个新的连通分量
                if (!visited[i][j] && grid[i][j] == 1) {
                    dfs(grid, visited, i, j);
                    res++;
                }
            }
        }
        System.out.println(res);
    }
    
    // 将一个连通分量上的所有结点都标记为true
    // 这里可以用深度搜索，也可以用广度搜索
    private static void dfs(int[][] grid, boolean[][] visited, int x, int y) {
        visited[x][y] = true;
        // 上下左右四个方向深度搜索
        for (int i = 0; i < 4; i++) {
            int newx = x + dir[i][0];
            int newy = y + dir[i][1];
            if (newx < 0 || newx >= grid.length || newy < 0 ||newy >= grid[0].length) {
                continue;
            }
            if (!visited[newx][newy] && grid[newx][newy] == 1) {
                dfs(grid, visited, newx, newy);
            }
        }
    }
}
```

上一题改过来的，这是实际上就是求最大的连通分量节点个数。那么直接在每个连通分量的搜索中统计数据即可。

##### BFS

```java
public class Main {
    private static final int[][] dir = {
        {0, 1},
        {0, -1},
        {1, 0},
        {-1, 0}
    };
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[][] grid = new int[m][n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        
        int res = 0;
        boolean[][] visited = new boolean[m][n];
        for (int i = 0; i < m ; i++) {
            for (int j = 0; j < n; j++) {
                if (!visited[i][j] && grid[i][j] == 1) {
                    res = Math.max(res, bfs(grid, visited, i, j));
                }
            }
        }
        System.out.println(res);
    }
    
    public static int bfs(int[][] grid, boolean[][] visited, int x, int y) {
        Deque<int[]> que = new LinkedList<>();
        que.add(new int[]{x, y});
        visited[x][y] = true;
        int res = 1;
        
        while (!que.isEmpty()) {
            int[] node = que.poll();
            for (int i = 0; i < 4; i++) {
                int newx = node[0] + dir[i][0];
                int newy = node[1] + dir[i][1];
                if (newx < 0 || newx >= grid.length || 
                    newy < 0 || newy >= grid[0].length) {
                    continue;
                }
                if (!visited[newx][newy] && grid[newx][newy] == 1) {
                    res++;
                    visited[newx][newy] = true;
                    que.add(new int[]{newx, newy});
                }
            }
        }
        return res;
    }
}
```

```java
public class Main {
    private static final int[][] dir = {
        {0, 1},
        {0, -1},
        {1, 0},
        {-1, 0}
    };
    private static int count;
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[][] grid = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        int res = 0;
        boolean[][] visited = new boolean[m][n];
        // 左右两边
        for (int i = 0; i < m; i++) {
            if (grid[i][0] == 1 && !visited[i][0]) {
                dfs(grid, visited, i, 0);
            }
            if (grid[i][n - 1] == 1 && !visited[i][n - 1]) {
                dfs(grid, visited, i, n - 1);
            }
        }
        // 上下两边
        for (int j = 0; j < n; j++) {
            if (grid[0][j] == 1 && !visited[0][j]) {
                dfs(grid, visited, 0, j);
            }
            if (grid[m - 1][j] == 1 && !visited[m - 1][j]) {
                dfs(grid, visited, m - 1, j);
            }
        }
        
        // 统计数清零
        count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {

                }
```

#### 8. [水流问题](https://kamacoder.com/problempage.php?pid=1175)

现有一个 N × M 的矩阵，每个单元格包含一个数值，这个数值代表该位置的相对高度。矩阵的左边界和上边界被认为是第一组边界，而矩阵的右边界和下边界被视为第二组边界。

矩阵模拟了一个地形，当雨水落在上面时，水会根据地形的倾斜向低处流动，但只能从较高或等高的地点流向较低或等高并且相邻（上下左右方向）的地点。我们的目标是确定那些单元格，从这些单元格出发的水可以达到第一组边界和第二组边界。

输入描述：

第一行包含两个整数 N 和 M，分别表示矩阵的行数和列数。

后续 N 行，每行包含 M 个整数，表示矩阵中的每个单元格的高度。

输出描述：

输出共有多行，每行输出两个整数，用一个空格隔开，表示可达第一组边界和第二组边界的单元格的坐标，输出顺序任意。

输入示例：

```text
5 5
1 3 1 2 4
1 2 1 3 2
2 4 7 2 1
4 5 6 1 1
1 4 1 2 1
```

输出示例：

```text
0 4
1 3
2 2
3 0
3 1
3 2
4 0
4 1
```

![image-20250120152033463](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250120152033463.png)

----

直观想法，遍历每个点，然后开始搜索，看看能不能到达第一组边界和第二组边界

但是这种暴力解法肯定是超时的

遍历每一个节点，是 `m * n`

遍历每一个节点的时候，都要做深搜，深搜的时间复杂度是： `m * n`

那么整体时间复杂度 就是 `O(m^2 * n^2)`  这是一个四次方的时间复杂度



##### 优化

从第一组边界上的节点逆流而上，将遍历过的节点都标记上，同样从第二组的边界逆流而上，并将遍历过的节点也标记上

两方都标记过的节点就是所求节点

```java
public class Main {
    //方向
    private static final int[][] dir = {
        {0, 1},
        {0, -1},
        {-1, 0},
        {1, 0}
    };
    // 深度遍历模板
    public static void dfs(int[][] grid, boolean[][] visited, int x, int y) {
        visited[x][y] = true;
        for (int i = 0; i < 4; i++) {
            int newx = x + dir[i][0];
            int newy = y + dir[i][1];
            if (newx < 0 || newx >= grid.length || newy < 0 || newy >= grid[0].length) {
                continue;
            }
            // 只是在这里加了一个判断，保证是逆流而上的
            if (!visited[newx][newy] && grid[x][y] <= grid[newx][newy]) {
            	dfs(grid, visited, newx, newy);
            }
        }
    }
    
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[][] grid = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        
        // 第一边界向上遍历的点
        boolean[][] firstBoundary = new boolean[m][n];
        // 第二边界向上遍历的点
        boolean[][] secondBoundary = new boolean[m][n];
        
        for (int i = 0; i < m; i++) {
            dfs(grid, firstBoundary, i, 0);
            dfs(grid, secondBoundary, i, n - 1);
        }
        
        for (int j = 0; j < n; j++) {
            dfs(grid, firstBoundary, 0, j);
            dfs(grid, secondBoundary, m - 1, j);
        }
        // 两次都遍历到的点，打印输出
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (firstBoundary[i][j] && secondBoundary[i][j]) {
                    System.out.println(i + " " + j);
                }
            }
        }
        
    }
}
```

时间复杂度是o(m * n)

前两个for循环的时间复杂度是 m * n * 2，每个for都是完整遍历一次图

最后打印是 m * n

所以时间复杂度是  m * n * 2 + m * n，即O(m * n)

暴力解法

遍历地图，尝试将每一个0改为1，然后去搜索地图中的最大岛屿面积

计算地图的最大面积：遍历地图 + 深搜岛屿，时间复杂度为 n ^ 2

##### 优化

优化重复操作

- 一次遍历，计算出各个岛屿的面积，并做编号记录

  可以用map记录，key岛屿编号，value岛屿面积，

  时间复杂度 n * n，因为每个节点只遍历一次

  ![image-20250120160418603](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250120160418603.png)

- 二次遍历，遍历0的方格，并统计该 1 周边岛屿的面积，将相邻面积加在一起，从而选出最大面积

  ![img](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/20220829105249.png)

  时间复杂度 n * n， 所以总体时间复杂度为O(n * n)

```java
// 记录每个岛屿的节点个数
private static int count;
// 记录方向
private static int[][] dir = {
    {0, 1},
    {0, -1},
    {1, 0},
    {-1, 0}
};

// 正常深度遍历
// 遍历方式也可以用广度遍历
public static void dfs(int[][] grid, boolean[][] visited, int x, int y, int mark) {
    visited[x][y] = true;
    count++;
    grid[x][y] = mark;
    for (int i = 0; i < 4; i++) {
        int newx = x + dir[i][0];
        int newy = y + dir[i][1];
        if (newy < 0 || newy >= grid[0].length ||
            newx < 0 || newx >= grid.length) {
            continue;
        }
        if (!visited[newx][newy] && grid[newx][newy] != 0) {
            dfs(grid, visited, newx, newy, mark);
        }
    }
}

public static void bfs(int[][] grid, boolean[][] visited, int x, int y, int mark) {
    Deque<int[]> que = new LinkedList<>();
    visited[x][y] = true;
    grid[x][y] = mark;
    que.offer(new int[]{x, y});
    
    while (!que.isEmpty()) {
		int[] cur = que.poll();
        count++;
        for (int i = 0; i < 4; i++) {
            int newx = cur[0] + dir[i][0];
            int newy = cur[1] + dir[i][1];
            if (newx < 0 || newx >= grid.length || newy < 0 ||
                newy >= grid[0].length) {
                continue;
            }
            if (!visited[newx][newy] && grid[newx][newy] > 0) {
                que.offer(new int[]{newx, newy});
                visited[newx][newy] = true;
            }
        }
    }
}

public static void main (String[] args) {
    Scanner sc = new Scanner(System.in);
    int m = sc.nextInt();
    int n = sc.nextInt();
    int[][] grid = new int[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            grid[i][j] = sc.nextInt();
        }
    }
	// 为每个岛屿进行标记
    int mark = 2;
    // 存储每个编号的岛屿对应的面积
    Map<Integer, Integer> map = new HashMap<>();
    // 标记是否全是陆地
    boolean isAllIsland = true;
    // 是否遍历过
    boolean[][] visited = new boolean[m][n];

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            // 如果有水存在则不是陆地
            if (grid[i][j] == 0) {
                isAllIsland = false;
            }
            if (grid[i][j] == 1 && !visited[i][j]) {
                // 将计数置为0
                count = 0;
                // 进行深度遍历
                dfs(grid, visited, i, j, mark);
                // （岛屿编号，面积）存入map集合
                map.put(mark, count);
                // 更新mark编号
                mark++;
            }
        }
    }

    // 最大岛屿面积
    int res = 0;
    // 全是陆地
    if (isAllIsland) {
        res = m * n;
    }

    // 统计每次遍历已经计算过的岛屿编号
    Set<Integer> set = new HashSet<>();
    
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            // 如果是海水
            if (grid[i][j] == 0) {
                set.clear();
                // 记录此次遍历岛屿面积总和
                int curSize = 1;
                // 四个方向找是否有存在的岛屿
                for (int z = 0; z < 4; z++) {
                    // 获取上下左右节点坐标
                    int sidex = i + dir[z][0];
                    int sidey = j + dir[z][1];
                    if (sidex < 0 || sidey < 0 || sidex >= m || sidey >= n) {
                        continue;
                    }
                    // 获取当前节点所在岛屿编号
                    int curMark = grid[sidex][sidey];
                    // 当前相邻的岛屿已经遍历过 或者 HashMap中不存在这个编号，则继续搜索
                    if (set.contains(curMark) || !map.containsKey(curMark)) {
                        continue;
                    }
                    // 记录此次遍历的岛屿编号
                    set.add(curMark);
                    // 累加面积
                    curSize += map.get(curMark);
                }
                /// 统计最大面积
                res = Math.max(res, curSize);
            }
        }
    }
    System.out.println(res);
}
```

```java
    Scanner sc = new Scanner(System.in);
    int n = sc.nextInt();
    String beginstr = sc.next();
    String endstr = sc.next();
    List<String> words = new ArrayList<>();
    words.add(beginstr);
    words.add(endstr);
    for (int i = 0; i < n; i++) {
        words.add(sc.next());
    }

    int count = bfs(beginstr, endstr, words);
    System.out.println(count);
}

private static int bfs(List<String> wordList, String beginStr, String endStr) {
    Set<String> set = new HashSet<>(wordList);
    Set<String> isVisited = new HashSet<>();
    Deque<String> queue = new LinkedList<>();

    isVisited.add(beginStr);
    queue.offer(beginStr);
    queue.offer(null);

    int len = 1;

    while (!queue.isEmpty()) {
        String s = queue.poll();
        if (s == null) {
            if (!queue.isEmpty()) {
                queue.offer(null);
                len++;
            }
            continue;
        }
        char[] chars = s.toCharArray();
        for (int i = 0; i < chars.length; i++) {
            char old = chars[i];
            for (char j = 'a'; j <= 'z'; j++) {
                chars[i] = j;
                String newWord = new String(chars);
                if (set.contains(newWord) && !isVisited.contains(newWord)) {
                    queue.offer(newWord);
                    isVisited.add(newWord);
                    if (newWord.equals(endStr)) {
                        return len + 1;
                    }
                }
            }
            chars[i] = old;
        }
    }
    return 0;
}
```

## 二 并查集

#### 1. 理论知识

并查集常用来解决**连通性问题**，就是用来**判断两个元素是否在同一个集合**

- 将两个元素添加到一个集合中
- 判断两个元素在不在同一个集合

##### 原理讲解

我们将三个元素A，B，C 放在同一个集合，只需要用一个一维数组来表示，即：father[A] = B，father[B] = C 这样就表述 A 与 B 与 C连通了（有向连通图）

```java
// 将v -> u这条边加入并查集
public void join(int u, int v) {
	// 寻找u的根
    u = find(u);
    // 寻找v的根
    v = find(v);
    // 如果发现根相同，那么说明在一个集合中，不用两个节点相连，直接返回
    if (u == v)
    	return;
    father[v] = u;
}
```

这样可以知道A连通B，因为A是索引下标，根据father[A]的数值就知道A连通B，那么怎么知道B连通A呢

我们的目的是判断，这三个元素是否在同一个集合中，知道A连通B就可以了，只要A， B， C 在同一个根下就是同一个集合。

**寻根过程**

```java
// 并查集寻根过程
public int find(int u) {
    // 根是自己，直接返回
    if (u == father[u])
        return u;
    // 根不是自己，根据father数组向上找
    return find(father[u]);
}
```

对于根C来说，需要father[C] = C，即C的根也为C。这样就可以表示A，B，C都在同一个集合里了。

所以father数组在**初始化**的时候，要`father[i] = i`，默认自己指向自己

```java
// 并查集初始化
public void init() {
    for (int i = 0; i < n; i++) 
        father[i] = i;
}
```

最后如何判断两个元素是都在同一个集合中，是通过find函数找根，如果两个元素的根一样的话，就是在同一集合中

```java
// 判断 u， v是否在同一个集合中
public boolean isSame(int u, int v) {
    return find(u) == find(v);
}
```



##### 路径压缩

在find函数的搜寻过程中，不断获取father数组下标对应的数值（也就是其父节点），最终找到整个集合的根，像是一个多叉树从叶子搜寻到根节点的过程

<img src="https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250123011524529.png" alt="image-20250123011524529" style="zoom:50%;" />

如果这颗多叉树高度很深的话，每次find函数寻找都要递归很多次，我们的目的只需要这些节点在同一个根下即可。所以可以通过**路径压缩**将多叉树的所有非根节点的所有节点直接指向根节点

<img src="https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250123012016210.png" alt="image-20250123012016210" style="zoom:50%;" />

只需要在递归过程中，让`father[u] = find(father[u]);`，让u的根节点成为它的父节点

```java
public int find(int u) {
    if (u == father[u])
        return u;
    return father[u] = find(father[u]);
    // 简化
    // return u == father[u] ? u : (father[u] = find(father[u]));
}
```

##### 代码模板

```java
// n 的大小依题目节点数量而定，一般比节点数量大一点
int n = 1000;
int[] father = new int[n];

// 初始化
void init() {
	for (int i = 0; i < n; i++) 
		father[i] = i;
}

// 将 v->u这条边加入并查集
void join(int u, int v) {
    u = find(u);
    v = find(v);
    if (u == v)
        return;
    father[v] = u;
}

// 并查集里寻根的过程
int find(int u) {
    return u == father[u] ? u :(father[u] = find(father[u]));
}

// 判断u和v是否在同一个根中
boolean isSame(int u, int v) {
    u = find(u);
    v = find(v);
    return u == v;
}
```

所以并查集有三大功能

- 寻找根节点，函数`int find(int u)`，也就是判断这个节点的祖先节点是哪个
- 将两个节点接入到同一个集合中，函数`void join(int u, int v)`，将两个节点连在同一个根节点上
- 判断两个节点是否在同一个集合中，函数`boolean isSame(int u, int v)`，判断两个节点是否是同一个根节点



##### 常见误区

是否可以在`join`函数中直接调用`isSame`函数来判断 u 和 v是否在同一个根中，比如

```java
void join(int u, int v) 
    // u = find(u);
    // v = find(v);
    // if (u == v) 
    //	return;
    if (isSame(u, v))
        return;

    father[v] = u;
}
```

这样实际上是有问题的，在**原来的`join`中**，u 和 v在调用`find`函数后已经不是它们原来的节点了，而是原来节点的根节点。也就是说，实际上在使用`join`函数的时候，并不是直接把 u和 v 连线在一起的，而是**连接它们的根。**

使用**错误写法**的例子如下：

```java

```

##### **按秩合并**

按秩合并也是一种缩短查询根节点的时候，rank表示树的高度，即树中节点层次的最大值。

比如两个集合合并

<img src="https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250123020856067.png" alt="image-20250123020856067" style="zoom:67%;" />

树1 的 rank为2，树2 的rank为3

![并查集树的合并方式](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250123021001402.png)

这里可以看出树2合并入树1会导致整个树的高度变高，而树1合入树2整个树的高度和树2保持一致

所以在`join`函数中，一定是**rank小的树合并入rank大的树中**，这样可以保证最后合成的树rank最小，从而降低在树上查询的路径长度

按秩合并的代码如下

```java
int n = 1000;
int[] father = new int[n];
// 记录每棵树的高度，一开始要将高度全部初始化为1
int[] rank = new int[n];

// 初始化
void init() {
    Arrays.fill(rank, 1);
    for (int i = 0; i < n; i++)
        father[i] = i;
}

// 将v->u这条边加入到并查集
void join(int u, int v) {
    u = find(u);
    v = find(v);
    // rank小的树合并到rank大的树
    if (rank[u] <= rank[v])
        father[u] = v;
    else
        father[v] = u;
    
    // 如果两颗树高度相同，那么v的高度加一
    // 因为上面在高度相同的情况下，是 father[u] = v
    // 只有在高度相同的情况下才更新rank，因为如果高度不同，那么rank是不变的
    if (rank[u] == rank[v] && u != v)
        rank[v]++;
}

// 寻根
int find(int u) {
    return u == father[u] ? u : (father[u] = find(father[u]));
}

// 判断 u和v 是否是同一个根
boolean isSame(int u, int v) {
 	return find(u) == find(v);   
}
```

上面的`join`函数中是没有做路径压缩的，因为一旦做了路径压缩，那么rank记录的高度就不准了，也就没有意义了

按秩合并的思路并没有将并查集树尽可能地扁平化，所以在整体效率上没有路径压缩高

在路径压缩策略中，调用`join`和`isSame`函数都会调用`find`查询操作，所以第二次访问相同的节点的时候，这个节点一定是直连根节点的，在第一次访问的时候它的路径就被压缩了



##### 复杂度分析

- **空间复杂度O(N)**，申请一个father数组
- **时间复杂度O(logn)到O(1)**，并且随着查询或者合并操作的增加，时间复杂度会越来越趋向O(1)

```java
public class Main {
    
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int n ,m;
        n = sc.nextInt();
        m = sc.nextInt();
        DisJoint disJoint = new DisJoint(n + 1);
        for (int i = 0; i < m; i++) {
            disJoint.join(sc.nextInt(), sc.nextInt());
        }
        System.out.println(disJoint.isSame(sc.nextInt(), sc.nextInt()) ? 1 : 0);
    }
}
class DisJoint {
    private int[] father = new int[101];
    
    DisJoint(int n) {
        init(n);
    }
    
    public boolean isSame(int u, int v) {
        return find(u) == find(v);
    }
    
    public int find(int u) {
        return u == father[u] ? u : (father[u] = find(father[u]));
    }
    
    public void join(int u, int v) {
        u = find(u);
        v = find(v);
        if (u == v) {
            return;

        father[v] = u;
    }

        for (int i = 1; i <= n; i++) {
            father[i] = i;
        }
    }
}
```

  ```java
  private static boolean IsTreeAfterRemove(Node[] nodes, List<Edge> edges, Edge e) {
      DisJoint disJoint = new DisJoint(nodes.length);
      for (Edge edge : edges) {
          if (edge == e) {
              continue;
          }
          if (disJoint.isSame(edge.s, edge.e)) {
              return false;
          }
          disJoint.join(edge.s, edge.e);
      }
      return true;
  }
  ```
  
- `getRemoveEdge`，确定图中一定有了有向环，那么要找到需要删除的那条边

  ```java
  private static Edge getRemoveEdgeInCycle(Node[] nodes, List<Edge> edges) {
      DisJoint disJoint = new DisJoint(nodes.length);
      for (Edge edge : edges) {
          if (disJoint.isSame(edge.s, edge.e)) {
              return edge;
          }
          disJoint.join(edge.s, edge.e);
      }
      return null;
  }
  ```

图中有n个结点，那么一定可以用n-1条边将所有结点连接在一起

![image-20250123172148944](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250123172148944.png)

**prim**算法就是从节点采用贪心的策略**每次寻找距离最小生成树最近的节点加入到最小生成树**

1. **选距离生成树最近节点**
2. **最近节点加入生成树**
3. **更新非生成树节点到生成树的距离（更新minDistance数据）**

prim算法中有两个数组很重要

- `isInTree[n]`

  是一个boolean类型的数组，用于判断某个节点是否已经加入到最小生成树中

- `minDist[n]`

  用于记录每个节点距离最小生成树的最近距离

```java
import java.util.*;
 
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int[][] grid = new int[n + 1][n + 1];
        for (int[] g : grid) {
            Arrays.fill(g, Integer.MAX_VALUE);
        }
     
        for (int i = 0; i < m; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            int val = sc.nextInt();
            grid[s][e] = grid[e][s] = val;
        }
 
        int[] minDistance = new int[n + 1];
        Arrays.fill(minDistance, Integer.MAX_VALUE);
        minDistance[1] = 0;

        boolean[] isInTree = new boolean[n + 1];
 
        for (int i = 0; i < n; i++) {
            int cur = 0, minVal = Integer.MAX_VALUE;
            for (int j = 1; j <= n; j++) {
                if (!isInTree[j] && minDistance[j] < minVal) {
                    cur = j;
                    minVal = minDistance[j];
                }
            }
            isInTree[cur] = true;
            for (int j = 1; j <= n; j++) {
                if (!isInTree[j] 
                   && grid[cur][j] != Integer.MAX_VALUE && grid[cur][j] < minDistance[j]) {
                    minDistance[j] = grid[cur][j];
                }
            }
        }
 
        int res = 0;
        for (int i = 2; i <= n; i++) {
            res += minDistance[i];
        }
        System.out.print(res);
    }
}
```

时间复杂度为O(n ^ 2)，n为节点数量

#### 2. kurscal算法

##### 理论

prim 算法是维护节点的集合，而 Kruskal 是维护边的集合。

kruscal算法每次选择一条边权值最小的边，使边的两边连通。原本两端就连通的话就不选。

kruscal算法的步骤：

1. 对**边的权值进行排序**，因为**优先选择最小边**加入到生成树中
2. 遍历排序后的边
   - 如果边两端的两个节点在同一个连通分量中，说明连上这条边会出现环
   - 如果边两端的两个节点不在一个联通分量中，加入到最小生成树，并把两个节点加入同一个连通分量中

如何判断两个节点是否在同一个连通分量中，那就要用到并查集了

```java
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int v = sc.nextInt();
        int e = sc.nextInt();
        List<Edge> edges = new ArrayList<>();
        for (int i = 0; i < e; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            int val = sc.nextInt();
            edges.add(new Edge(s, e, val));
        }
        // 按照边的权值对边进行从小到大的排序
        edges.sort((o1, o2) -> (o1.val - o2.val));
        DisJoint disJoint = new DisJoint(n):
        
        int resVal = 0;
        // 从头开始遍历
        for (Edge edge : edges) {
            
            int x = disJoint.find(edge.s);
            int y = disJoint.find(edge.e);
            // 祖先不同
            if (x != y) {
                resVal += edge.val;
                join(x, y);
            }
        }
        System.out.println(resVal);
    }
    
    static class Edge {
        int s;
        int e;
        int val;
        Edge(int s, int e, int va;) {
            this.s = s;
            this.e = e;
            this.val = val;
        }
    }
    
    static class DisJoint {
        private int[] father;
        DisJoint(int n) {
            init(n);
        }
        public void init(int n) {
			father = new int[n + 1];
            for (int i = 1; i <= n; i++) {
                father[i] = i;
            }
    	}
        public int find(int u) {
            return u == father[u] ? u : (father[u] = find(father[u]));
        }
        public void join(int u, int v) {
            u = find(u);
            v = find(v);
            if (u == v) {
                return;
            }
            father[v] = u;
        }
        public boolean isSame(int u, int v) {
            return find(u) == find(v);
        }
    }
}
```

**2. prim 和 kruscal比较**

prim维护的是节点的集合，而 Kruskal 维护的是边的集合。 如果 一个图中，节点多，但边相对较少，那么使用Kruskal 更优。

- 因为 Kruskal 是对边进行排序的后 进行操作是否加入到最小生成树。边如果少，那么遍历操作的次数就少。

  在节点数量固定的情况下，图中的边越少，Kruskal 需要遍历的边也就越少。

- 而 prim 算法是对节点进行操作的，节点数量越少，prim算法效率就越优。

**所以在 稀疏图中，用Kruskal更优。 在稠密图中，用prim算法更优。**

> 边数量较少为稀疏图
>
> 接近或等于完全图（所有节点皆相连）为稠密图

Prim 算法 时间复杂度为 **O(n^2)**，其中 n 为节点数量，它的运行效率和图中边树无关，适用**稠密图**

Kruskal算法 时间复杂度 为 **eloge**，其中e 为边的数量，适用**稀疏图**

#### 2. 堆优化版

dijkstra算法的朴素版时间复杂度为 O(n^2)，时间复杂度 只和 n （节点数量）有关系。如果n很大的话，我们可以换一个角度来优先性能。

在最小生成树部分，有两个算法：prim（点少边多）和kruscal算法（边少点多）

同样，在dijkstra算法中，也可以采用这种解决办法

##### 理论

在朴素版dijkstra算法中，整个算法是套在一个for循环里的，因为它是从节点的角度来解决问题

第一步，选择距离源点最近且未被访问过的节点，这个操作本身就需要进行for循环遍历，通过minDist数组找到最近的节点

同时还要遍历所有尚未访问的节点，所以从节点的角度来说，会有两层for循环



那么从**边的角度**出发，在处理**选择距离源点最近且未被访问过的节点**的时候，就不用遍历所有节点了

直接**把带权值的边加入到小顶堆**，利用堆来进行自动排序，那么**每次从堆顶中取出的边，自然就是距离源点最近节点所在的边**。这样就不需要两层for循环来找最近距离的点了



整体思路依然是三步骤

- 第一步，选源点到哪个节点近且该节点未被访问过
- 第二步，该最近节点被标记访问过
- 第三步，更新非访问节点到源点的距离（即更新minDist数组）

只不过这里只通过堆来堆边进行排序，达到直接选择距离源点最近的节点

```java
import java.util.*;

        for (int i = 0; i <= n; i++) {
            adjList.add(new ArrayList<>());
        }
        for (int i = 0; i < m; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            int val = sc.nextInt();
            adjList.get(s).add(new Edge(e, val));
        }

        int[] minDistance = new int[n + 1];
        Arrays.fill(minDistance, Integer.MAX_VALUE);
        minDistance[1] = 0;

        boolean[] isVisited = new boolean[n + 1];

        PriorityQueue<Node> pq = new PriorityQueue<>();
        pq.offer(new Node(1, 0));

        while (!pq.isEmpty()) {
            Node cur = pq.poll();
            int s = cur.id;
            if (isVisited[s]) {
                continue;
            }
            isVisited[s] = true;
            for (Edge edge : adjList.get(s)) {
                int e = edge.e;
                int val = edge.val;
                if (!isVisited[e] && val + minDistance[s] < minDistance[e]) {
                    minDistance[e] = minDistance[s] + val;
                    pq.offer(new Node(e, minDistance[e]));
                }
            }
        }
        System.out.println(minDistance[n] != Integer.MAX_VALUE ? minDistance[n] : -1);
    }

    static class Node implements Comparable<Node> {
        int id;
        int dist;
        Node(int id, int dist) {
            this.id = id;
            this.dist = dist;
        }

        @Override
        public int compareTo(Node other) {
            return Integer.compare(this.dist, other.dist);
        }
    }

    static class Edge {
        int e;
        int val;
        Edge(int e, int val) {
            this.e = e;
            this.val = val;
        }
    }
}
```





## 六 Bellman_ford 

#### 1. 单源最短路径（存在负权值边）

 [城市间货物运输](https://kamacoder.com/problempage.php?pid=1152)

![image-20250124233009573](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250124233009573.png)

本题依旧是**单源最短路径**问题，求 从 节点1 到节点n 的最小费用。 但本题不同之处在于 **边的权值是有负数了**。

从 节点1 到节点n 的最小费用也可以是负数，**费用如果是负数** 则表示 **运输的过程中 政府补贴大于运输成本**，说明有**盈利**了。

在求单源最短路的方法中，使用**dijkstra 的话，则要求图中边的权值都为正数**。

本题是经典的**带负权值的单源最短路问题**，此时就用Bellman_ford算法了

> 该算法是由 R.Bellman 和L.Ford 在20世纪50年代末期发明的算法，故称为Bellman_ford算法。

Bellman_ford算法的核心思想是：**对<u>*所有边*</u>进行松弛n-1次操作（n为节点数量），从而求得目标最短路。**

> 对所有边进行松弛，也就意味着代码实现是要用**边列表（edge list）**形式来存储图



##### 理论

**什么是松弛**

![image-20250124233232610](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250124233232610.png)

看这个例子，每条边有起点、终点和边的权值，**minDist[B] 表示 到达B节点 最小权值**

`minDist[B]`可以由

- minDist[A] + value 推出
- minDist[B]本身就有权值 （可能是其他边链接的节点B ，例如节点C，以至于 minDist[B]记录了其他边到minDist[B]的权值）

本题要求最小权值，那么就取这两个之中小的那个就行了

```java
if (minDist[A] + value < minDist[B]) {
    minDist[B] = minDist[A] + value;
}
```

也就是说，如果通过A 到 B这条边可以获得更短的到达B节点的路径，

即如果`minDist[B] > minDist[A] + value`，那么我们更新`minDist[B] = minDist[A] + value;`，这个过程就叫**松弛**

这段代码也就是Bellman_ford算法的核心操作，采用了动态规划的思想



**为什么是n-1次松弛呢**

这里采用模拟过程的形式进行说明，依然使用minDist数组来表达 起点到各个节点的最短距离

对所有边**松弛一次**，相当于计算 **起点到达 与起点一条边相连的节点** 的**最短距离**



上面的距离中，我的得到离 **起点达到 与 一条边相邻的节点2 和 节点3**的最短距离，分别是 minDist[2] 和 minDist[3]

这里对于minDist[3] = 5，分明不是 起点到达 节点3 的最短距离，节点1 -> 节点2 -> 节点5 -> 节点3 这条路线距离是4



因为**对所有边松弛一次**，**相当于计算 起点到达 与起点一条边相连的节点的最短距离**，这里说的是一条边相连的节点

与起点（节点1）一条边相邻的节点，到达节点2最短距离为1，到节点3最短距离5

而节点1 -> 节点2 -> 节点5 -> 节点3 这条路线 是 **与起点三条边相连**的路线

- 所以对所有边**松弛一次** 能得到 与**起点 一条边相连的节点**最短距离
- 所以对所有边**松弛两次** 能得到 与**起点 两条边相连的节点**最短距离
- 所以对所有边松弛三次 能得到 与起点 三条边相连的节点最短距离，这时候我们才得到到达节点3的真正最短距离：节点1 -> 节点2 -> 节点5 -> 节点3 这条路线

**所以对于n个节点的有向图来说，无论图是什么样的，从起点到终点最多 n - 1条边相连，那么对所有边进行n - 1次松弛，就一定能得到起点到达终点的最短距离**

由此可得出以下来两点推论（**前提是不存在负权回路**）

- 大多数时候其实用不到松弛n - 1次就能得出结果的，松弛n - 1次是保证多任何图都能求得到终点的最小距离

- 松弛 n+ 次对结果是没有影响的，松弛在n - 1次及之后，minDist数组就不会发生变化了

##### 实现

```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
StringTokenizer st = new StringTokenizer(br.readLine());

int n = Integer.parseInt(st.nextToken());
int m = Integer.parseInt(st.nextToken());

List<Edge> edges = new ArrayList<>();

for (int i = 0; i < m; i++) {
    st = new StringTokenizer(br.readLine());
    int s = Integer.parseInt(st.nextToken());
    int e = Integer.parseInt(st.nextToken());
    int val = Integer.parseInt(st.nextToken());
    edges.add(new Edge(s, e, val));
}

int[] minDist = new int[n + 1];
Arrays.fill(minDist, Integer.MAX_VALUE);
minDist[1] = 0;

// 有个n个点，松弛n - 1次，找到起点到达 与 起点n - 1条边 相连的节点的最短距离
for (int i = 1; i < n; i++) {
    // 每一次松弛，都要对有边进行扫描
    for (Edge edge : edges) {
        // 松弛操作
        // minDist[edge.s] != Integer.MAX_VALUE 是用来防止从未计算过的节点出发
        if (minDist[edge.s] != Integer.MAX_VALUE 
            && minDist[edge.s] + edge.val < minDist[edge.e]) {
            minDist[edge.e] = minDist[edge.s] + edge.val;
        }
    }
}

// 不能到达终点
if (minDist[n] == Integer.MAX_VALUE) {
    System.out.println("unconnected" );
} else {
    System.out.println(minDist[n]);
}
```

- 时间复杂度： O(N * E) , N为节点数量，E为图中边的数量

  ​				因为要进行 n - 1次松弛，每次松弛都要遍历 e 条边

- 空间复杂度： O(N) ，即 minDist 数组所开辟的空间



##### 队列优化算法 SPFA

本题我们来系统讲解 **Bellman_ford 队列优化算法** ，也叫SPFA算法

Bellman_ford算法每次松都是对所有边松弛，但是**真正有效的松弛是 基于已经计算过的节点在做的松弛**

比如上题的例子

![image-20250126020808287](https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250126020808287.png)

第一次松弛，传统的bellman_ford会对所有边都松弛一次，但是真正有效的松弛 边（1 -> 2）、边（1 -> 3）

而松弛边（2 -> 3）、边（2 -> 5）等都是无效的操作，因为其他节点都是没有被计算过的节点

所以Bellman_ford算法每次都是对所有边进行松弛，其实就是做了一些无用功

##### SPFA实现

```java
public class Main {
    static class Edge {
        int e;
        int val;
        Edge(int e, int val) {
            this.e = e;
            this.val = val;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        List<List<Edge>> edges = new ArrayList<>();
        for (int i = 0; i <= n; i++) {
            edges.add(new LinkedList<>());
        }

        for (int i = 1; i <= m; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            int val = sc.nextInt();
            edges.get(s).add(new Edge(e, val));
        }

        int start = 1, end = n;

        int[] minDist = new int[n + 1];
        Arrays.fill(minDist, Integer.MAX_VALUE);
        minDist[start] = 0;

        boolean[] visited = new boolean[n + 1];
        Queue<Integer> que = new LinkedList<>();
        que.offer(start);

        while (!que.isEmpty()) {
            int s = que.poll();
        	// 从队列里取出的时候，要取消标记，我们只保证已经在队列里的元素不用重复加入
            visited[s] = false;

            for (Edge edge : edges.get(s)) {
                // 开始松弛
                if (minDist[s] + edge.val < minDist[edge.e]) {
                    minDist[edge.e] = minDist[s] + edge.val;
                }
                // 已经在队列里的元素不用重复添加
                if (!visited[edge.e]) {
                    que.offer(edge.e);
                    visited[edge.e] = true;
                }
            }
        }

        if (minDist[end] == Integer.MAX_VALUE) {
            // 不能到达终点
            System.out.println("unconnected");
        } else {
            // 到达终点的最短路径
            System.out.println(minDist[end]);
        }
    }
}
```



#### 2. 单源最短路径（存在负权回路）

[城市间货物运输](https://kamacoder.com/problempage.php?pid=1153)

本题是上一题的的延申

本题存在负权回路的问题，所以要判断负权回路，也就是图中出现环且环上的边总权值为负数。

负权回路存在的**问题**：在这样的图中求最短路的话， 就会在这个环里无限循环 （也是负数+负数 只会越来越小），无法求出最短路径。

在不存在负权回路的图中，松弛n次以上，结果不会有变化

但是本题有负权回路，如果松弛n次，那么结果就会有变化，因为有负权回路 就是可以无限最短路径（一直在负权回路中绕圈）

<img src="https://typora-image-jiege.oss-cn-hangzhou.aliyuncs.com/jiegeisstudyingjava-12581/image-20250125012526220.png" alt="image-20250125012526220" style="zoom:50%;" />

比如在这个有向图中，节点1到节点4的最短路径应该是：1 2 3 4，路径总成本为1

但是有负权回路，在负权回路中多绕了一圈，最短路径就 变得更小了.

节点1 -> 节点2 -> 节点3 -> 节点1 -> 节点2 -> 节点3 -> 节点4，这样的路径总成本 (-1) + 1 + (-1) + (-1) + 1 + (-1) + 1 = -1

这样就无解了

本题的核心思路就是在上一题n-1次松弛的基础上，再多松弛一次，看看minDist数组是否有变化

```java
int[] minDistance = new int[n + 1];
Arrays.fill(minDistance, Integer.MAX_VALUE);
minDistance[1] = 0;

for (int i = 0; i < n - 1; i++) {
    for (Edge edge : edges) {
        if (minDistance[edge.s] != Integer.MAX_VALUE
            && minDistance[edge.s] + edge.val < minDistance[edge.e]) {
                minDistance[edge.e] = edge.val + minDistance[edge.s];
            }
    }
}

boolean isCircle = false;
for (Edge edge : edges) {
    if (minDistance[edge.s] != Integer.MAX_VALUE
        && minDistance[edge.s] + edge.val < minDistance[edge.e]) {
        isCircle = true;
        break;
    }
}

if (isCircle) {
    System.out.print("circle");
} else if (minDistance[n] == Integer.MAX_VALUE) {
    System.out.print("unconnected");
} else {
    System.out.print(minDistance[n]);
}
```



#### 3. [单源最短路径（有限最短路）](https://kamacoder.com/problempage.php?pid=1154)

题目中描述是 最多经过 k 个城市的条件下，而不是一定经过k个城市，也可以经过的城市数量比k小，但要最短的路径。

而bellman_ford算法是：对所有边松弛n次，相当于计算起点 到 与起点一条边相连结点的最短距离。如果节点数为n，那么起点到终点最多是n - 1条边相连，那么对所有边松弛n - 1次就一定能得到起点到终点的最短距离。

以上是对所有边进行的第一次松弛，最后minDist数组为 -1, -1, 0, 1

后续的几次松弛结果如下，第二次-2, -2, -1, 0；第三次-3, -3, -2, -1；第四次 -4，-4，-3，-2（k = 3）

所以最后的结果是-2，即起点到节点4 最多经过3个节点的最短距离是 -2，节点1 -> 节点2 -> 节点3 -> 节点4

理论上来说，对所有边松弛一次，相当于计算起点到达与起点一条边相连的节点的最短距离。

但是在对所有边松弛第一次的时候，所有节点都更新了，不仅仅是与起点第一条边相连的节点。而且在所有边的后面几次松弛，同样是更新了所有节点，说明至少经过 k 个 节点这个限制没有起作用。

在上面的第一次松弛中，在计算节点2 -> 节点3的时候，更新了节点3。理论上说，节点3应该对所有边第二次松弛的时候才更新，这是因为基于已经计算好的minDist[2]来计算的，这是由于**边的顺序**导致的，如果节点2 -> 节点3是第一条边，那么就不会这样。

这就造成了一个情况，**即在计算minDist数组的时候，基于了本次松弛的minDist数值，而不是上一次松弛的时候minDist数值**

所以最终实现如下：

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        List<Edge> edges = new ArrayList<>();

        for (int i = 0; i < m; i++) {
            int s = sc.nextInt();
            int e = sc.nextInt();
            int val = sc.nextInt();
            edges.add(new Edge(s, e, val));
        }

        int src = sc.nextInt();
        int dist = sc.nextInt();
        int k = sc.nextInt();

        int[] minDistance = new int[n + 1];
        Arrays.fill(minDistance, Integer.MAX_VALUE);
        minDistance[src] = 0;

        int[] minDistanceCopy;

        for (int i = 0; i < k + 1; i++) {
            minDistanceCopy = Arrays.copyOf(minDistance, n + 1);
            for (Edge edge : edges) {
                if (minDistanceCopy[edge.s] == Integer.MAX_VALUE) {
                    continue;
                }
                if (minDistanceCopy[edge.s] + edge.val < minDistance[edge.e]) {
                    minDistance[edge.e] = minDistanceCopy[edge.s] + edge.val;
                }
            }
        }

        if (minDistance[dist] == Integer.MAX_VALUE) {
            System.out.println("unreachable");
        } else {
            System.out.println(minDistance[dist]);
        }
    }
}

class Edge {
    int s;
    int e;
    int val;
    Edge(int s, int e, int val) {
        this.s = s;
        this.e = e;
        this.val = val;
    }
}
```

##### 要点一 边的顺序

上面提到了边的顺序会影响每一次松弛的结果

同样的图，边的顺序不一样，那么直接使用bellman_ford算法每次松弛更新的节点也是不一样的

边的顺序是随机的，所以本题的最终实现才要采用上一次松弛的minDist，来保障每一次对所有边松弛的结果



##### 要点二 本题的本质

为什么本题相较于前面两题要采用minDistCopy呢

- 对于[城市间货物运输](https://programmercarl.com/kamacoder/0094.%E5%9F%8E%E5%B8%82%E9%97%B4%E8%B4%A7%E7%89%A9%E8%BF%90%E8%BE%93I.html)来说，是没有负权回路的，松弛n - 1次够了，次数大于n - 1次，结果也不会变，那么在对所有边进行第一次松弛的时候，如果基于本题计算的minDist来计算minDist（相当于多做松弛），对最后的结果是没有结果的
- 对于[城市间货物运输Ⅱ](https://programmercarl.com/kamacoder/0095.%E5%9F%8E%E5%B8%82%E9%97%B4%E8%B4%A7%E7%89%A9%E8%BF%90%E8%BE%93II.html)来说，只是判断是否有负权回路，一旦有负权回路，那么对所有边松弛n - 1次之后，再继续做松弛，minDist的数值一定会变的，根据这一点来判断是否有负权回路。所以这题只需要进行判断有无负权回路，而无需对其进行处理

本题的minDist计算一定要基于minDistCopy是因为

- 本题会出现负权回路，说明只要多做松弛，结果是会变的
- 本题最多经过k个节点，对松弛次数是有限制的



##### 要点三 SPFA实现

本题可以用SPFA来实现，关键在于如何控制松弛 k 次

可以用一个变量记录size每一轮松弛入队列的所有节点数量，下一轮松弛的时候，就把队列里size个节点弹出来，就是上一轮松弛入队列的节点

```java
public class Main {
    static class Edge {
        int e;
        int val;
        Edge(int e, int val) {
            this.e = e;
            this.val = val;
        }
    }
    
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt():
        int m = sc.nextInt():
        List<List<Edge>> adjs = new ArrayList<>();
        
        for (int i = 0; i <= m; i++) {
            adjs.add(new LinkedList<>());
        }
        
        for (int i = 1; i <= m; i++) {
			int s = sc.nextInt():
            int e = sc.nextInt():
            int val = sc.nextInt():
            adjs.get(s).add(new Edge(e, val));
        }
        
        int src = sc.nextInt():
        int dst = sc.nextInt():
        int k = sc.nextInt():
        
        int[] minDist = new int[n + 1];
        Arrays.fill(minDist, Integer.MAX_VALUE);
        minDist[src] = 0;
        int[] minDistCopy;
        
        Deque<Integer> que = new LinkedList<>();
        que.offer(src);
        int size = 0;
        
        while ((k-- != 0) && !que.isEmpty()) {
            // 获取上一次计算的结果
            minDistCopy = Arrays.copyOf(minDist, n + 1);
            // 获取上一轮入队列的节点个数
            size = que.size();
            // 上一轮松驰入队列的节点，这次的对应边都要做松弛
            while (size-- != 0) {
                int s = que.poll();
                for (Edge edge : adjs.get(s)) {
					if (minDistCopy[s] + edge.val < minDist[edge.e]) {
						minDist[edge.e] = minDistCopy[s] + edge.val;
                        que.offer(edge.e);
                    }
                }
            }
        }
        if (minDist[dst] == Integer.MAX_VALUE) {
			System.out.println("unreachable");
        } else {
            System.out.println(minDist[dst]);
        }
    }
}
```

## 七 Floyd

[小明逛公园](https://kamacoder.com/problempage.php?pid=1155)

本题是一个经典的**多源最短路**问题，前面的算法都是单源最短路径，即只能有一个起点

本题是求 **多个起点到多个终点的多条最短路径**，本题采用Floyd算法

Floyd 算法对边的权值正负没有要求，都可以处理，Floyd算法核心思想就是**动态规划**



假如我们求节点1到节点9最短距离，用二维数组来表示即`grid[1][9]`，如果最短距离为10，是`grid[1][9]`=10

那么节点1到节点9的最短距离 可以由节点 1 到 节点5的最短距离 + 节点5 到节点9的最短距离组成

`grid[1][9] = grid[1][5] + grid[5][9]`

节点1到节点5的最短距离，可以有节点1到节点3的最短距离 + 节点3到节点5的最短距离组成

`grid[1][5] = grid[1][3] + grid[3][5]`

以此类推，节点1到节点3的最短记录可以由更小的区间，从而由子问题推导求出整体最优方案



##### 理论

1. 确定动态数组及其下标的含义

`dp[i][j][k]`：节点 `i` 到节点 `j`  以`[1, k]`集合中的一个节点为中间节点的最短距离

节点 i 到 节点 j 中间一定要经过很多节点，就是用`[1,k]`来表示中间的节点，表示一个集合，节点1到节点k一共k个节点集合



2. 确定递推集合

- 节点 i 到 节点 j 的最短路径**经过节点 k**

`grid[i][j][k] = grid[i][k][k - 1] + grid[k][j][k - 1]`

**节点 i 到节点 k** 的最短距离是不经过节点 k， 中间节点集合是`[1, k - 1]`

**节点 k 到节点 j** 的最短距离是不经过节点 j，中间节点集合是`[1, k - 1]`

- 节点 i 到 节点 j 的最短路径**不经过节点 k**

`grid[i][j][k] = grid[i][j][k - 1]`

节点 i 到节点 k 的最短距离是不经过节点 k， 中间节点集合是`[1, k - 1]`

所以最终的递推公式是：

`grid[i][j][k] = min(grid[i][k][k - 1] + grid[k][j][k - 1]， grid[i][j][k - 1])` 



3. dp数组如何初始化

`grid[i][j][k] = m`，表示 节点i 到 节点j 以[1...k] 集合为中间节点的最短距离为m

刚开始时初始化k时不确定的

假如题目中只是输入边（2 -> 6, val = 3），那么`grid[2][6][k] = 3`，只能把 k 填成 0，本题节点 0 是无意义的，因为节点的范围是1到n

这样我们在下一轮计算的时候，就可以根据`grid[i][j][0]`来计算`grid[i][j][1]`，此时`grid[i][j][1]`就是节点 i 经过节点 1 到达节点 j 的最小距离

红色的底层是初始化好的数据，本题是一个三位的动态数组

4. 确定遍历顺序

由递推公式`grid[i][j][k] = min(grid[i][k][k - 1] + grid[k][j][k - 1]， grid[i][j][k - 1])` 可只，需要三个for循环，分别遍历 i j k

而 **k 依赖于 k - 1， i 和 j  并不依赖于 i - 1 和 j - 1**

在初始化中，我们将 k = 0 的 i 和 j都初始化了，这样才能计算 k = 1的时候 i 和 j对应的数值

所以遍历的顺序是从底层往上遍历

所以 k 的遍历一定在最外面，这样才能一层一层去遍历

至于 i 和 j， 这两个遍历顺序倒无所谓、

##### 空间优化

这里可以做一个空间的优化，从滚动数组的角度，我们定义`grid[n + 1][n + 2][2]`这么大的数组，因为 k 只是依赖于 k - 1的状态，并不需要记录 k - 2，k - 3，k - 4

那么只需要`grid[i][j][1]`和`grid[i][j][0]`，之后就是`grid[i][j][1]`和`grid[i][j][0]`

在进一步，如果本层计算（本层计算即 k 相同，从三维角度）

- 如果本层的`grid[i][j]`用到了本层刚好计算好的比上一层（即k - 1层）计算的`grid[i][k]`小，说明确实有 i 到 k 的更短路径，那么基于更小的`grid[i][k]`去计算`grid[i][j]`是没问题的
- 如果本层的`grid[i][j]`用到了本层刚好计算好的比上一层（即k - 1层）计算的`grid[i][k]`大，这不可能，因为这样也不会做更新`grid[i][k]`

所以本层计算中，使用了本层计算过的 `grid[i][k]` 和 `grid[k][j]` 是没问题的

那么就没必要区分，`grid[i][k]`和`grid[k][j]`是属于 k - 1层还是 k 层的

```java
private static final int MAX_VALUE = 10005;

int[][] grid = new int[n + 1][n + 1];
for (int i = 0; i <= n; i++) {
    for (int j = 0; j <= n; j++) {
        grid[i][j] = MAX_VALUE;
    }
}

for (int i = 0; i < m; i++) {
    int s = sc.nextInt();
    int e = sc.nextInt();
    int val = sc.nextInt();
    
    grid[s][e] = val;
    grid[e][s] = val;
}

for (int k = 1; k <= n; k++) {
	for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            grid[i][j] = Math.min(grid[i][j], grid[i][k] + grid[k][j]);
        }
    }
}
```

##### 理论

Astar 是一种 **广搜的改良版**。 有的是 Astar是 dijkstra 的改良版。其实只是**场景不同**

我们在搜索最短路的时候，

- 如果是**无权图**（边的权值都是1） 那就用广搜，代码简洁，时间效率和 dijkstra 差不多 （具体要取决于图的稠密）

- 如果是**有权图**（边有不同的权值），优先考虑 dijkstra。

而 Astar 关键在于 **启发式函数**， 也就是 影响 广搜或者 dijkstra **从 容器（队列）里取元素的优先顺序**。

**以下是BFS版本的A *** 

在BFS中，我们想搜索，从起点到终点的最短路径，要一层一层去遍历。

相比较于BFS没有目的性的 一圈一圈去搜索， 而 A * 是**有方向性的去搜索**，从而节省很多没有必要的遍历步骤，就是**启发式函数**指引A*算法有目的性地搜索的

在BFS算法中，指引搜索方法地关键代码是

```java
int mm=m + dir[i][0];
int nn=n + dir[i][1];
```

从队列里去除什么元素，接下来就是从哪里开始搜索，所以**启发式函数就是改变队列里元素的排序**，这就是寻找方向的关键

对队列里的元素进行排序，给每一个节点权值，设每个节点的权值为F，给出公式为：F = G + H

- G：起点达到目前遍历节点的距离
- H：目前遍历的节点到达终点的距离



**起点达到目前遍历节点的距离** + **目前遍历的节点到达终点的距离** 就是起点到达终点的距离

本题的图是无权网格图，计算距离通常采用三种计算方式

- 曼哈顿距离，计算方式： d = abs(x1-x2)+abs(y1-y2)
- 欧氏距离（欧拉距离） ，计算方式：d = sqrt( (x1-x2)^2 + (y1-y2)^2 )
- 切比雪夫距离，计算方式：d = max(abs(x1 - x2), abs(y1 - y2))

不同的距离计算方式会导致算法的结果不同，本题采用欧氏距离算法，它可以最大程度上体现点与点之间的距离

##### 实现

```java
import java.util.*;
import java.io.*;

public class Main {

    // moves 数组用于记录从起点到每个位置的最小步数
    private static int[][] moves;

    // dir 数组定义了骑士可以移动的 8 个方向
    private static int[][] dir = {
        {-1, -2},
        {-1, 2},
        {1, -2},
        {1, 2},
        {-2, -1},
        {-2, 1},
        {2, -1},
        {2, 1}
    };

    // 定义 Knight 类，表示骑士在棋盘上的状态
    private static class Knight implements Comparable<Knight> {
        int x, y; // 当前骑士的位置 (x, y)
        int g, h, f; // g: 从起点到当前位置的实际步数, h: 启发式估计值, f: 总优先级评分 (f = g + h)

        // 构造函数初始化骑士的状态
        Knight(int x, int y, int g, int h) {
            this.x = x;
            this.y = y;
            this.g = g;
            this.h = h;
            this.f = g + h; // 计算总优先级评分
        }

        @Override
        public int compareTo(Knight knight) {
            return Integer.compare(this.f, knight.f);
        }
    }

    // 启发式函数：计算当前位置到目标位置的欧几里得距离的平方
    private static int dist(int a1, int a2, int b1, int b2) {
        return (a1 - b1) * (a1 - b1) + (a2 - b2) * (a2 - b2);
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        // 读取测试用例的数量
        int cnt = Integer.parseInt(st.nextToken());
        while (cnt-- > 0) {
            st = new StringTokenizer(br.readLine());

            // 读取起点和终点的坐标
            int a1 = Integer.parseInt(st.nextToken());
            int a2 = Integer.parseInt(st.nextToken());
            int b1 = Integer.parseInt(st.nextToken());
            int b2 = Integer.parseInt(st.nextToken());

            // 初始化 moves 数组，清零以避免前一次的计算结果干扰
            moves = new int[1001][1001];

            // 调用 A* 算法计算从起点到终点的最短路径
            aStar(new Knight(a1, a2, 0, dist(a1, a2, b1, b2)), b1, b2);

            System.out.println(moves[b1][b2]);
        }
    }

    // A* 算法实现
    private static void aStar(Knight knight, int b1, int b2) {
        // 使用优先队列存储待扩展的节点，按 f 值从小到大排序
        PriorityQueue<Knight> pq = new PriorityQueue<>();
        pq.offer(knight); // 将起始节点加入优先队列

        // 开始 A* 搜索
        while (!pq.isEmpty()) {
            Knight cur = pq.poll(); // 取出优先队列中 f 值最小的节点
            if (cur.x == b1 && cur.y == b2) {
                return;
            }
            
            // 遍历骑士可以移动的 8 个方向
            for (int[] d : dir) {
                int newx = cur.x + d[0]; // 计算新位置的 x 坐标
                int newy = cur.y + d[1]; // 计算新位置的 y 坐标

                // 如果新位置超出棋盘范围，跳过
                if (newx < 1 || newy < 1 || newx > 1000 || newy > 1000) {
                    continue;
                }

                if (moves[newx][newy] == 0) {
                    moves[newx][newy] = moves[cur.x][cur.y] + 1;
                    pq.offer(new Knight(newx, newy, cur.g + 5, 
                                dist(newx, newy, b1, b2)));
                }
            }
        }
    }
}
```



##### 复杂度

A * 算法的时间复杂度 其实是不好去量化的，因为他取决于 启发式函数怎么写。

最坏情况下，A * 退化成广搜，算法的时间复杂度 是 O(n * 2)，n 为节点数量。

最佳情况，是从起点直接到终点，时间复杂度为 O(dlogd)，d 为起点到终点的深度。

因为在搜索的过程中也需要堆排序，所以是 O(dlogd)。



##### 拓展

A * 算法 并不是一个明确的最短路算法，**A \* 算法搜的路径如何，完全取决于 启发式函数怎么写**。

**A \* 算法并不能保证一定是最短路**，因为在设计 启发式函数的时候，要考虑 时间效率与准确度之间的一个权衡。

在游戏开发设计中，**保证运行效率的情况下，A \* 算法中的启发式函数 设计往往不是最短路，而是接近最短路的 次短路设计**。



##### 缺点

相对了 普通BFS，A * 算法只从 队列里取出 距离终点最近的节点。

A * 在一次路径搜索中，大量不需要访问的节点都在队列里，会造成空间的过度消耗。

另外还有一种场景 是 A * 解决不了的。

如果题目中，给出 多个可能的目标，然后在这多个目标中 选择最近的目标，这种 A * 就不擅长了， A * 只擅长给出明确的目标 然后找到最短路径。

如果是多个目标找最近目标（特别是潜在目标数量很多的时候），可以考虑 Dijkstra ，BFS 或者 Floyd
